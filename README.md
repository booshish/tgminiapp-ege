# Точка — подготовка к ОГЭ и ЕГЭ

Существующее приложение на **Next.js 15, React 19, TypeScript, Tailwind CSS и KaTeX**. Доступны математика ОГЭ, базового и профильного ЕГЭ. Сохранены Onest, две темы, режим концентрации и прежние пользовательские данные. Приложение работает без сервера, аккаунтов, Telegram SDK и платежей.

Сайт: https://booshish.github.io/tgminiapp-ege/

## Серии, возврат к практике и мобильная теория

Исправлен повторный сброс Win Streak: серия учитывает только первую проверку уникальной задачи первой части. Повторная проверка уже учтённого задания не меняет её. На главной сохранены общая и предметная серии; добавлены компактные счётчики в «Прогресс» и каталог математики, доступные бесплатно.

«Задания» при возвращении из другого раздела открывают последнюю задачу текущего экзамена. Каждый номер/тема/тип сохраняют собственную позицию; явный выбор нового номера имеет приоритет. «К выбору заданий» и повторное нажатие активной вкладки открывают каталог. На главной — «Продолжить решение» с названием сохранённого задания. Стабильный ID передаётся в ссылке `task=…`; индекс сохраняется только для совместимости старых ссылок.

Хранилище `tochka-practice-v1` мигрирует в схему 2 без нового ключа: общий `taskStates[id]` для черновиков и состояния проверки, сессии с контекстом и последним ID. Повреждённые записи не затираются пустыми. Между устройствами синхронизации пока нет.

«Сохранить» находится внутри шапки краткого и полного конспекта, состояние «Сохранено» использует прежнее избранное. На телефонах текст теории — 16 px / 400 / 1,6; планшетные настройки сохранены. Для длинных формул добавлен понятный локальный скролл. Акцент «Без карты» убран из заголовка trial; действующие условия раскрываются отдельно, оплата по-прежнему отключена.

Подробные причины, файлы и проверки — [отчёт по доработкам](docs/study-return-verification.md).

## Возможности

- Каталог «По номеру» / «По теме», отдельные части, выбор прототипа. Случайная подборка перемешивает варианты воспроизводимо и сначала предлагает ещё не проверенные задачи. Банк конечный, дневных ограничений нет.
- Бесплатная теория для всех 25 номеров ОГЭ и 19 номеров ЕГЭ профиль: объяснения, формулы, примеры, типичные ошибки, темы-предпосылки и переход к связанной практике. Поиск и фильтры по части/номеру.
- До проверки обычной задачи видны только условие и ввод. После проверки — вердикт; разбор открывается отдельно. Неверный ответ можно исправить в поле. Подсказок и кнопки «Решить заново» нет.
- Точная проверка рациональных чисел и наборов значений: запятая/точка, отрицательные числа и допустимые эквивалентные дроби. Числа не сравниваются после грубого округления.
- «Предыдущее»/«Следующее» сохраняют ввод, проверки и раскрытие решения. Возврат к каталогу сохраняет фильтры и прокрутку. Закладка или ошибка открывает именно выбранный вариант по стабильному ID.
- **Избранное бесплатно:** задачи и целые темы, фильтры по экзамену, предмету и типу; сохранение после перезагрузки, без дублей и ссылок на недоступные материалы. Выделение отдельных формул пока не реализовано.
- **«Мои ошибки» бесплатно:** ручной возврат к неверным ответам и связанной теории, фильтр исправленных задач. Без сводных процентов и глубокой аналитики.
- **Учебные варианты бесплатно:** все 25/19 номеров, согласованное общее условие ОГЭ №1–5, таймер, пропуск и возврат, сохранение черновиков, завершение и история. Вторая часть — явно обозначенная самопроверка, не проверка преподавателем.
- **В деморежиме Premium:** интервальное повторение после ошибки с новым вариантом того же прототипа, интервалы 1/3/7/14/30 дней; рекомендации сложности после минимум шести разных самостоятельных попыток. При устойчивом успехе предлагается реально более сложная доступная задача, при ошибках — фундаментальная теория. Ученик выбирает сам. Если новые варианты исчерпаны, это прямо указано.
- Прогноз баллов **не запущен**. Созданы только отключённая модель данных и [предложение методики](docs/score-forecast-proposal.md), требующие согласования и проверки точности.

Переход к повышенной сложности сейчас обеспечен 12 дополнительными задачами ОГЭ №6/9 и ЕГЭ №6/7. Для остальных тем предложение «сложнее» появится только после добавления действительно более сложных вариантов; приложение не переименовывает обычную задачу ради рекомендации.

## XP, серии и доступ

Существующий единый журнал XP сохранён. В первой части самостоятельный правильный ответ даёт XP один раз за уникальную задачу. Просмотр решения до успеха блокирует XP; исправление ошибки без просмотра может дать XP, но не восстанавливает прерванную серию. Во второй части самопроверка начисляет выбранные баллы, а редактирование меняет только разницу с сохранённой оценкой. Правила Free и Premium одинаковы.

Навигация и перезагрузка не создают попыток. Проверки завершённого учебного варианта записываются с постоянными ID запросов; повторная публикация не дублирует попытку или XP. Просмотр решения пропущенного задания фиксируется без выдуманного ответа и блокирует будущие XP за него.

Общий XP — сумма предметных; дневной считается по локальным календарным суткам. 150 XP — только конец фиолетовой шкалы, а не ограничение заработка. Общий и предметные уровни, серии и огоньки бесплатны. Серия учитывает только самостоятельные первые проверки новых задач первой части; неверная первая проверка сбрасывает общую серию и серию соответствующего предмета. Повторная проверка этой задачи и самопроверка второй части не меняют серию.

Free получает теорию, неограниченную практику и проверку, решения после проверки, XP, ручные ошибки, закладки и базовые результаты учебных вариантов. Premium — сводная аналитика, автоматические повторения и персональные рекомендации. Полный персональный план, диагностическая методика и дневник подготовки ещё не реализованы. Публичных рейтингов нет.

В обычной сборке Premium закрыт информационным экраном. Для локальной проверки работающих демонстрационных функций:

```bash
NEXT_PUBLIC_ENABLE_PREMIUM_DEMO=true npm run dev
```

Затем **Профиль → демонстрационный доступ Premium**. Это незашищённый разработческий режим, не покупка или серверная подписка. Публичная сборка и GitHub Actions используют выключенный флаг. Реальные права доступа потребуют сервера и авторизации.

## Данные, миграции и наполнение

Серверной БД нет, поэтому SQL-миграция и привязка закладок к аккаунту невозможны. Пользовательские записи не удаляются при наполнении банка:

- `tochka-learning-v2`: действующая схема 3, учебные события, настройки и игровой журнал версии 2; старые форматы мигрируются существующим кодом.
- `tochka-practice-v1`: схема 2, миграция старых сессий, позиции по стабильным ID, единые черновики/проверки задач и раскрытые решения.
- `tochka-study-tools-v2`: закладки, безопасная миграция из версии 1, нормализация прежних ссылок теории.
- `tochka-mock-exams-v1`: варианты, дедлайны, черновики, результаты и самопроверки.

Нечитаемые записи не перезаписываются пустыми данными; интерфейс предупреждает об ограничениях сохранения. Закладки синхронизируются между вкладками одного браузера. Одновременная работа с учебными журналами в разных вкладках не является серверной транзакцией. Очистка данных браузера или сброс из профиля удаляет локальную историю. Между устройствами данные не переносятся; от редактирования localStorage клиент не защищён.

Контент хранится в типизированных данных `src/lib/content/`, новые варианты детерминированы. Генераторы проверяются независимыми вычислениями, ограничениями параметров, уникальностью и KaTeX. Повторяемый seed содержит только контент и SHA-256, не данные ученика:

```bash
npm run content:check
npm run content:report
npm run content:seed -- /tmp/tochka-content-seed.json
```

`content:check` проверяет связи задач, прототипов, тем, статей, реестра баллов и совместимость исходных ID. `content:report` обновляет таблицы. Экспорт предназначен для проверки и будущего серверного импорта; базы данных он не создаёт.

## Чтение и оформление

Ровно две темы: светлая по умолчанию и тёмная в **Профиль → Настройки → Оформление**. Кнопок темы в шапке и концентрации нет. Сохранены обычный/крупный/очень крупный текст и настройки перерывов.

Длинная теория на планшетах от 768 px использует колонку до **640 px**, Onest **20 px / 500 / 1,65**, интервалы между абзацами 20 px. На телефоне до 600 px — **16 px / 400 / 1,6**, заголовки шагов 20 px, примеров 18 px, метки 13 px; обычный рендер формул около 17,85 px. На промежуточной ширине 601–767 px сохранён прежний текст 17 px / 400 / 1,6. Существующие настройки увеличения текста продолжают работать. Формулы прокручиваются внутри блока с подсказкой при переполнении, не всей страницы. На телефонах сокращены отступы карточек XP, но сохранены размеры чисел, толщина шкалы, цвета и огоньки. Концентрация скрывает второстепенные действия и сохраняет состояние.

## Запуск и публикация

Редактировать файлы для просмотра не нужно. На компьютере или в облачной среде с Node.js 22:

```bash
npm ci
npm run dev
```

Открыть http://localhost:3000. В облачной среде — **Preview / Ports → 3000**, если эта функция доступна. `localhost` на iPad относится к самому iPad; для просмотра готового сайта используй адрес GitHub Pages выше.

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

Для GitHub Pages:

```bash
npm run build:pages
```

Готовые файлы — `out/`, base path `/tgminiapp-ege/`, `.nojekyll`, hash-маршруты. Команда собирает сайт, но сама его не публикует. Workflow `.github/workflows/pages.yml` при отправке `main` выполняет проверки и публикацию через GitHub Actions, если этот способ выбран в Settings → Pages. Также поддерживается публикация готового `out/` из ветки `gh-pages` → `/(root)`. Статус: https://github.com/booshish/tgminiapp-ege/actions .
