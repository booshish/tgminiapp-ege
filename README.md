# Точка — демо подготовки к ОГЭ и ЕГЭ

Мобильное образовательное веб-приложение на Next.js, TypeScript и Tailwind CSS. Интерфейс полностью на русском, адаптирован для телефона, iPad и компьютера.

## Что работает

- Главная, каталог с выбором ОГЭ/ЕГЭ и математики, теория, задания, прогресс, персональный тренер и профиль.
- Пять базовых задач: прямоугольный треугольник, уравнение, дроби, вероятность и проценты. Это общие учебные примеры для ОГЭ и ЕГЭ, а не полные экзаменационные варианты.
- Проверка ответа с объяснением решения и самостоятельный переход к следующему заданию. Поддерживаются десятичная запятая, точка и запись дробью: `0,8`, `0.8`, `4/5`.
- Четыре коротких конспекта по математике.
- Сохранение результатов проверок, количества попыток, выбранного экзамена и текущего задания в localStorage. Реальный прогресс демоверсии сохраняется после перезагрузки в том же браузере и по тому же адресу. При очистке данных браузера он удаляется.

## Что является демонстрацией

68% на главной, готовность к экзамену и проценты тем в тренере — подписанные примеры, а не диагностика ученика. Раздел «Прогресс» использует реальные ответы в этой демоверсии. «Решено задач» — количество уникальных задач с верным ответом. Доля верных ответов — число успешных ответов, делённое на количество всех проверенных числовых попыток; пустой или нечисловой ввод не учитывается. Уже решённая задача повторно не увеличивает счётчик. Данные хранятся только в браузере и не синхронизируются между устройствами.

Авторизации, оплаты, серверного ИИ, внешней базы данных и интеграции с Telegram пока нет. Тренер показывает пример рекомендаций и запускает обычную тренировку. Пункт «Premium — скоро» не блокирует обучение.

## Как открыть

**Если вы работаете только с iPad:** откройте проект в облачной среде разработки с поддержкой Node.js. В её терминале выполните команды ниже, затем откройте **«Предпросмотр» / Preview / Ports → порт 3000**. Если среда выдаёт ссылку, откройте её в Safari. Код вручную редактировать не нужно.

В этой рабочей сессии приложение запускается на порту 3000, но автоматически выданной публичной ссылки нет. Возможность открыть порт зависит от интерфейса среды. Адрес `localhost` на самом iPad не ведёт к серверу в облаке, а скачанный ZIP с кодом сам по себе не запускает Next.js.

Для запуска нужен Node.js 20.9 или новее. В папке проекта выполните:

```bash
npm install
npm run dev
```

При запуске на компьютере откройте [http://localhost:3000](http://localhost:3000) в браузере **этого же компьютера**.

На iPad откройте Safari и введите `http://IP-АДРЕС-КОМПЬЮТЕРА:3000`, например `http://192.168.1.20:3000`. Компьютер и iPad должны быть в одной сети Wi-Fi, сервер должен продолжать работать, а сетевой доступ к порту 3000 должен быть разрешён на компьютере.

Проект не опубликован автоматически: наличие публичной ссылки и её срок действия зависят от выбранного хостинга или среды разработки.

## Проверки и рабочая сборка

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

`npm start` запускает уже собранную версию на порту 3000. Перед этим остановите сервер разработки, если он занимает тот же порт.

`npm test` проверяет ответы задач, разные форматы чисел, повреждённые сохранения и восстановление прогресса; новые библиотеки для тестов не нужны. Интерфейс дополнительно проверен в Chromium на ширинах 320, 390, 768, 1024 и 1440 px. Проверка в настоящем Safari на iPad пока не выполнялась.

## Структура

- `src/app/` — страницы, общий макет и стили.
- `src/components/screens/` — отдельные экраны приложения.
- `src/components/ui.tsx` — небольшие общие компоненты.
- `src/components/task-screen.tsx` — решение задач.
- `src/components/illustrations.tsx` — собственные SVG-рисунки.
- `src/hooks/` — сохранение прогресса и история переходов.
- `src/lib/demo.ts` — задачи, конспекты, проверка ответов и безопасное чтение прогресса.
- `scripts/test-demo.mjs` — проверки математических данных и сохранений.
