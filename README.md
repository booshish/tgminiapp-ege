# Точка — учебный MVP

Существующее приложение на **Next.js 15, React 19, TypeScript, Tailwind CSS и KaTeX**. Дизайн с Onest, молочным фоном, зелёными акцентами и собственным роботом сохранён. Telegram SDK, сервер, аккаунты и оплата не подключены.

Адрес GitHub Pages: https://booshish.github.io/tgminiapp-ege/

## Что работает сейчас

- Бесплатные теория, проверка каждого ответа и практика **без дневных лимитов**. Банк конечный; генерации новых задач нет.
- Доступны **21 авторская задача ОГЭ и 13 задач профильного ЕГЭ**. Ещё 16 прежних задач базы сохранены в данных для совместимости истории, но не доступны для практики: базовый ЕГЭ появится после проверки структуры и контента.
- Каталог «По номеру» / «По теме», фильтр прототипов, отдельные номера и части 1/2. Пустой номер показывает «Задания скоро появятся», без подмены чужим экзаменом.
- **8 бесплатных фундаментальных конспектов, 16 примеров**: дроби, десятичные числа, проценты, линейные и квадратные уравнения, степени и корни, геометрия, вероятность. Поиск, фильтр части/номера, краткое объяснение, «Разобрать подробнее», ссылки на темы-предпосылки и связанную практику. Теория части 2 пока не опубликована.
- Условие до проверки не раскрывает ответ. В первой части после проверки показаны вердикт, баллы текущего ответа и новый XP, если он реально начислен; разбор открывается отдельной кнопкой. Неверный ответ можно исправить прямо в поле. Подсказок и кнопки повторного решения нет. Во второй части образец открывается кнопкой «Проверить самостоятельно».
- Точная проверка рациональных чисел через целочисленные дроби, а не округление: принимаются запятая, точка, отрицательные значения, эквивалентные дроби и наборы корней без учёта порядка.
- «К выбору заданий» возвращает к тому же каталогу и позиции прокрутки. «Предыдущее задание» и «Следующее задание» сохраняют ответы, проверки и раскрытые решения. На последней задаче переход вперёд отключён. Перезагрузка сохраняет черновики и ID проверок; навигация не создаёт новые попытки.
- По умолчанию сохранена исходная светлая палитра: молочный фон и зелёные акценты. Тёмная и системная темы включаются только по выбору в профиле. Прежнее автоматическое следование теме устройства сбрасывается в светлую; вручную выбранная тёмная сохраняется. Также доступны крупный текст и режим концентрации с возвратом в каталог.

## Начисление XP: причина и исправление

Раньше `verifiedXPScoringRules` был пуст, а движок принимал только независимо проверенные правила. Любой ответ получал `null` вместо настройки баллов и давал 0 XP. Теперь действует отдельный реестр **конфигурации проекта** `configuredXPScoringRules` по сетке 2026 года из технического задания. Статус `project-config` не выдаётся за выполненную официальную проверку: ФИПИ из среды по-прежнему возвращает 403.

| Экзамен 2026 | Номера | Максимум первичных баллов |
| --- | --- | --- |
| ОГЭ, математика | 1–19 / 20–25 | 1 / 2 |
| ЕГЭ профиль, математика | 1–12 | 1 |
| ЕГЭ профиль, математика | 13, 15, 16 | 2 |
| ЕГЭ профиль, математика | 14, 17 | 3 |
| ЕГЭ профиль, математика | 18, 19 | 4 |

Правило привязано к году, версии экзамена, предмету, номеру, части и формату. Для неизвестной конфигурации, недоступной базы и фундаментального упражнения без экзаменационного номера XP не начисляется. Банк содержит **50 задач**, включая 16 прежних недоступных задач базы и **4 новые авторские задачи с самопроверкой**.

### Первая часть

- Реальный математический валидатор проверяет ответ. Первая самостоятельная верная проверка уникального варианта даёт XP по его номеру: для доступной первой части это 1 XP.
- Ошибка даёт 0 XP. Можно изменить ответ и проверить снова. Если готовое решение ещё не открывали, верное исправление даёт XP.
- Просмотр готового решения до верного ответа исключает XP за этот вариант. Этот факт сохраняется в учебном журнале и черновике.
- Уникальность определяется ID варианта, а не номером. Переходы, двойные нажатия, перезагрузка и другой режим каталога не начисляют дополнительные очки.
- «Верно! +1 XP» появляется только при новом начислении, не при повторном просмотре старого результата. Баллы текущего учебного ответа и игровой XP подписаны отдельно; это не официальный результат экзамена.

### Вторая часть

Доступны авторские примеры **ОГЭ №20**, **ЕГЭ профиль №13, №17 и №19**. До действия пользователя нет образца или ответа. Можно записать решение в поле или решить на бумаге, затем нажать «Проверить самостоятельно». Откроются образец, авторские ориентиры и ссылка на материалы ФИПИ. Авторские пояснения не названы официальными критериями.

Ученик выбирает целое число 0..максимум и подтверждает «Самооценка: N из M баллов». Подтверждение даёт N XP; изменение 2 → 3 → 1 создаёт дельты +2, +1, −2. Текущая оценка общая для всех режимов каталога, журнал и баланс сохраняются вместе. Самооценка не влияет на Win Streak и не попадает в статистику автоматически верных ответов.

Позднее исправление относится к первому дню положительного начисления за эту задачу. Например, если вчера поставлено 3, а сегодня исправлено на 1, вчерашний баланс уменьшается на 2, сегодняшняя шкала не становится отрицательной. Первоначальная оценка 0 не привязывает будущие первые положительные очки к пустому дню.

### Шкалы, уровни и миграции

Общий XP равен сумме предметных, без двойного начисления и платного множителя. Общая и предметная дневные шкалы — два представления одного журнала. **150 XP — только визуальный предел**: при 187 XP счётчик и накопление остаются 187, шкала — 150/150, ранг — «Радуга». Сохранились прежние цвета и формула: новый уровень за 100 XP.

Локальный день фиксируется с часовым смещением при начислении. Новый день сбрасывает только дневное отображение. Ошибки не отнимают XP, но исправление самооценки может уменьшать ранее заявленный опыт.

Серия учитывает только автоматические ответы первой части: ошибка сбрасывает общую серию и серию этого предмета; первое верное решение, включая исправление, увеличивает их. Правильное повторение уже решённого варианта не позволяет накручивать серию. Самооценка её не меняет. Все игровые механики бесплатны; рейтингов нет.

Игровой журнал мигрирует с v1 на v2 внутри прежнего `LearningState`. Из сохранённых полноценных событий восстанавливаются XP, ранее заблокированные пустым реестром: только известный номер/контекст, только правильный ответ до просмотра решения, с исходной датой. Краткие старые итоги без нужных метаданных не превращаются в выдуманные начисления. Прерванная цепочка самооценок восстанавливается из валидных подтверждений без повторной выдачи полной суммы.

### Как проверить в интерфейсе

1. **Задания → ОГЭ → №15**: для первого треугольника с катетами 6 и 8 введите `0,8`. У новой ещё не решённой задачи появится «Верно! +1 XP». На Главной общий и математический XP увеличатся на 1. Если задача уже решалась, начисление не повторяется.
2. На другой задаче введите неверный ответ, затем исправьте его, не открывая разбор. Верное исправление даст XP. Если сначала открыть решение — XP не будет.
3. **Задания → ЕГЭ → №19 → Проверить самостоятельно**: подтвердите 2, затем 3, затем 1. Опыт за эту задачу станет соответственно 2, 3 и 1; серия не изменится.
4. Перезагрузите страницу, вернитесь назад и откройте тот же вариант «По теме»: баланс и самооценка сохранятся, повторного начисления не будет.

Это **локальная демоверсия**, не защищённое облачное хранилище. В одном браузере используются синхронная запись журнала и чтение актуального состояния перед изменением; вкладки синхронизируются через событие `storage`. localStorage не является серверной транзакцией: намеренное редактирование, часы устройства и одновременные записи нескольких вкладок не обеспечивают коммерческой защиты. Для многопользовательского продукта нужны аккаунты, серверные права и идемпотентные транзакции.

## Экзаменационные источники

Карты **2026 года предварительные**, не являются официальным документом и не подтверждают соответствие 2027 году. ОГЭ: 25 номеров (1–19 / 20–25); профиль: 19 (1–12 / 13–19). У задач есть авторское происхождение, год/версия, часть, тема, прототип, сложность, формат и отдельный разбор. Полного охвата экзамена нет. Задач второй части с автоматической объективной оценкой нет.

## Free и Premium

Free получает всю опубликованную теорию, доступную практику, проверку, разбор после проверки и игровую мотивацию. **Накопительная учебная статистика скрыта на всех Free-экранах**: нет количества решённых задач/попыток, точности, истории ошибок и освоения тем.

«Прогресс» и «Мой тренер» в Free показывают описание Premium без учебных показателей. Информационная страница содержит проектные тарифы 200–600 ₽/мес., без покупки и оплаты.

Демонстрационный Premium включается только для разработки:

```bash
NEXT_PUBLIC_ENABLE_PREMIUM_DEMO=true npm run dev
```

Затем: **Профиль → Режим для разработчика**. После перезагрузки снова Free. В production-публикации переменная выключена. Это клиентская демонстрация, а не защищённая подписка.

В демо-Premium работают локальные результаты, попытки, ошибки и темы. Простой тренер отмечает тему после минимум трёх проверок при минимум двух ошибках. Это прозрачное правило, а не диагноз, полноценный учебный план или AI. Интервальное повторение и адаптивная диагностика остаются следующим этапом.

## Хранение и приватность

Данные остаются в localStorage этого браузера; не отправляются на сервер. Храним только настройки, ответы, события проверок/просмотра решения, каталог, черновики и игровой журнал. Паролей и персональных идентификаторов нет. Между устройствами данные не переносятся, удаление данных Safari их уничтожает.

- `tochka-learning-v2`: схема **v3** с игровым журналом v2, атомарная запись учебных событий, самооценок и XP, миграция прежней v2 и `tochka-demo-progress-v1` без выдуманного XP.
- `tochka-practice-v1`: версия 1, каталог, сессии, ответы, ID проверок и состояние решения.
- `tochka-catalog-scroll-v1`: версия 1, координаты окна и прокручиваемых контейнеров с безопасными локаторами.

Повреждённые записи проверяются, опасные контексты отбрасываются. При недоступном хранилище приложение предупреждает о возможной потере последних изменений. Профиль позволяет удалить локальные данные. Это не резервная копия и не серверная защита Premium.

## Запуск и сборка

Нужен Node.js 22 LTS. Ручное редактирование файлов не требуется.

```bash
npm ci
npm run dev
```

На компьютере открыть http://localhost:3000. В облачной среде открыть Preview / Ports → **3000**, если среда предоставляет эту возможность. `localhost` на iPad означает сам iPad, а не удалённый сервер.

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

Для GitHub Pages:

```bash
npm run build:pages
```

Получится `out/` с `.nojekyll` и base path `/tgminiapp-ege/`. Hash-навигация поддерживает прямые ссылки без серверных маршрутов. Команда только собирает файлы, сама ничего не публикует.

## Обновление через GitHub

Адрес проекта: https://booshish.github.io/tgminiapp-ege/

Поддерживаются два существующих варианта публикации:

1. **GitHub Actions:** Settings → Pages → Source → GitHub Actions. Workflow `.github/workflows/pages.yml` при обновлении `main` устанавливает зависимости, проверяет линтер, типы, тесты и собирает сайт, затем публикует Pages-артефакт. Статус — https://github.com/booshish/tgminiapp-ege/actions .
2. **Готовая ветка:** Settings → Pages → Deploy from a branch → `gh-pages` → `/(root)`. Ветка содержит содержимое `out`, а не исходники. При обновлении готовой ветки сайт пересобирается Pages.

Настройки Pages — свойство репозитория, их нельзя изменить одной лишь записью файлов. При недоступном GitHub API можно отправить исходники и готовую ветку, но нельзя достоверно проверить завершение публикации. Не присылайте токены или пароли в чат.
