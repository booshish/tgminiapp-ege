# Точка — учебный MVP

Существующее приложение на **Next.js 15, React 19, TypeScript, Tailwind CSS и KaTeX**. Дизайн с Onest, молочным фоном, зелёными акцентами и собственным роботом сохранён. Telegram SDK, сервер, аккаунты и оплата не подключены.

Адрес GitHub Pages: https://booshish.github.io/tgminiapp-ege/

## Что работает сейчас

- Бесплатные теория, проверка каждого ответа и практика **без дневных лимитов**. Банк конечный; генерации новых задач нет.
- Доступны **21 авторская задача ОГЭ и 13 задач профильного ЕГЭ**. Ещё 16 прежних задач базы сохранены в данных для совместимости истории, но не доступны для практики: базовый ЕГЭ появится после проверки структуры и контента.
- Каталог «По номеру» / «По теме», фильтр прототипов, отдельные номера и части 1/2. Пустой номер показывает «Задания скоро появятся», без подмены чужим экзаменом.
- **8 бесплатных фундаментальных конспектов, 16 примеров**: дроби, десятичные числа, проценты, линейные и квадратные уравнения, степени и корни, геометрия, вероятность. Поиск, фильтр части/номера, краткое объяснение, «Разобрать подробнее», ссылки на темы-предпосылки и связанную практику. Теория части 2 пока не опубликована.
- Условие до проверки не раскрывает ответ. В первой части после проверки показаны вердикт, баллы текущего ответа и новый XP, если он реально начислен; разбор открывается отдельной кнопкой. Неверный ответ можно исправить прямо в поле. Подсказок и кнопки повторного решения нет. Во второй части образец открывается кнопкой «Проверить самостоятельно».
- Точная проверка рациональных чисел через целочисленные дроби, а не округление: принимаются запятая, точка, отрицательные значения, эквивалентные дроби и наборы корней без учёта порядка.
- «К выбору заданий» возвращает к тому же каталогу и позиции прокрутки. «Предыдущее задание» и «Следующее задание» сохраняют ответы, проверки и раскрытые решения. На последней задаче переход вперёд отключён. Перезагрузка сохраняет черновики и ID проверок; навигация не создаёт новые попытки.
- Ровно две темы: светлая по умолчанию и тёмная по явному выбору в **Профиль → Настройки → Оформление**. Тема применяется ко всем экранам, включая концентрацию, и сохраняется; системное оформление не меняет её автоматически. Доступны обычный, крупный и очень крупный текст.

## Единый журнал XP и исправленные серии

Прежний баг с 0 XP был связан с пустым реестром баллов. В этом этапе существующий журнал сохранён: исправлены правила серий и восстановление старых событий, параллельная система не создавалась. Действует реестр **конфигурации проекта** `configuredXPScoringRules` по сетке 2026 года из технического задания. Статус `project-config` не выдаётся за выполненную официальную проверку: ФИПИ из среды по-прежнему возвращает 403.

| Экзамен 2026 | Номера | Максимум первичных баллов |
| --- | --- | --- |
| ОГЭ, математика | 1–19 / 20–25 | 1 / 2 |
| ЕГЭ профиль, математика | 1–12 | 1 |
| ЕГЭ профиль, математика | 13, 15, 16 | 2 |
| ЕГЭ профиль, математика | 14, 17 | 3 |
| ЕГЭ профиль, математика | 18, 19 | 4 |

Правило привязано к году, версии экзамена, предмету, номеру, части и формату. Для неизвестной конфигурации, недоступной базы и фундаментального упражнения без экзаменационного номера XP не начисляется. Банк содержит **50 задач**, включая 16 прежних недоступных задач базы и **4 новые авторские задачи с самопроверкой**.

### Первая часть

- Реальный математический валидатор проверяет ответ. Первая самостоятельная верная проверка уникального варианта даёт XP по его номеру: для доступной первой части это 1 XP.
- Ошибка даёт 0 XP. Можно изменить ответ и проверить снова. Если готовое решение ещё не открывали, верное исправление даёт XP.
- Просмотр готового решения до верного ответа исключает XP за этот вариант. Этот факт сохраняется в учебном журнале и черновике.
- Уникальность определяется ID варианта, а не номером. Переходы, двойные нажатия, перезагрузка и другой режим каталога не начисляют дополнительные очки.
- «Верно! +1 XP» появляется только при новом начислении, не при повторном просмотре старого результата. Баллы текущего учебного ответа и игровой XP подписаны отдельно; это не официальный результат экзамена.

### Вторая часть

Доступны авторские примеры **ОГЭ №20**, **ЕГЭ профиль №13, №17 и №19**. До действия пользователя нет образца или ответа. Можно записать решение в поле или решить на бумаге, затем нажать «Проверить самостоятельно». Откроются образец, авторские ориентиры и ссылка на материалы ФИПИ. Авторские пояснения не названы официальными критериями.

Ученик выбирает целое число 0..максимум и подтверждает «Самооценка: N из M баллов». Подтверждение даёт N XP; изменение 2 → 3 → 1 создаёт дельты +2, +1, −2. Текущая оценка общая для всех режимов каталога, журнал и баланс сохраняются вместе. Самооценка не влияет на Win Streak и не попадает в статистику автоматически верных ответов.

Позднее исправление относится к первому дню положительного начисления за эту задачу. Например, если вчера поставлено 3, а сегодня исправлено на 1, вчерашний баланс уменьшается на 2, сегодняшняя шкала не становится отрицательной. Первоначальная оценка 0 не привязывает будущие первые положительные очки к пустому дню.

### Шкалы, уровни и миграции

Общий XP равен сумме предметных, без двойного начисления и платного множителя. Общая и предметная дневные шкалы — два представления одного журнала. **150 XP — только визуальный предел**: при 187 XP счётчик и накопление остаются 187, шкала — 150/150. Названий рангов и радужного градиента нет. Цвет усиливается от серого к фиолетовому по девяти заданным ступеням; последняя — #5719E6. Формула уровня сохранена: новый уровень за 100 XP. Толщина полосы остаётся 9 px; размеры карточек не увеличены.

Локальный день фиксируется с часовым смещением при начислении. Новый день сбрасывает только дневное отображение. Ошибки не отнимают XP, но исправление самооценки может уменьшать ранее заявленный опыт.

Серия учитывает только новые верные автоматические ответы первой части **с первой попытки**. Два таких ответа дают серию 2. Ошибка сбрасывает общую серию и серию этого предмета; чужие предметные серии сохраняются. Исправление ошибки может дать XP, но не возвращает и не увеличивает серию. Просмотр решения, повторный вариант и самооценка её не увеличивают. В общей и предметных карточках есть огоньки: цвет и размер зависят только от серии, область всегда 36×36 px. После серии 50 иконка остаётся 34 px и #FF2929, само число продолжает расти. Все игровые механики бесплатны; рейтингов нет.

Игровой журнал мигрирует с v1 на v2 внутри прежнего `LearningState`. Из сохранённых полноценных событий восстанавливаются XP, ранее заблокированные пустым реестром: только известный номер/контекст, только правильный ответ до просмотра решения, с исходной датой. Для старых событий известной номерной задачи первой части восстанавливается безопасная проекция серии без изменения учебного журнала. Неоднозначный экзамен и упражнения без номера не подменяются первой частью. Краткие старые итоги без нужных метаданных не превращаются в выдуманные начисления. Прерванная цепочка самооценок восстанавливается из валидных подтверждений без повторной выдачи полной суммы.

### Как проверить в интерфейсе

1. **Задания → ОГЭ → №15**: для первого треугольника с катетами 6 и 8 введите `0,8`. У новой ещё не решённой задачи появится «Верно! +1 XP». На Главной общий и математический XP увеличатся на 1. Если задача уже решалась, начисление не повторяется.
2. На другой задаче введите неверный ответ, затем исправьте его, не открывая разбор. Верное исправление даст XP. Если сначала открыть решение — XP не будет.
3. **Задания → ЕГЭ → №19 → Проверить самостоятельно**: подтвердите 2, затем 3, затем 1. Опыт за эту задачу станет соответственно 2, 3 и 1; серия не изменится.
4. Перезагрузите страницу, вернитесь назад и откройте тот же вариант «По теме»: баланс и самооценка сохранятся, повторного начисления не будет.

Это **локальная демоверсия**, не защищённое облачное хранилище. В одном браузере используются синхронная запись журнала и чтение актуального состояния перед изменением; вкладки синхронизируются через событие `storage`. localStorage не является серверной транзакцией: намеренное редактирование, часы устройства и одновременные записи нескольких вкладок не обеспечивают коммерческой защиты. Для многопользовательского продукта нужны аккаунты, серверные права и идемпотентные транзакции.

## Справка, темы и концентрация

Под общей карточкой XP есть один текстовый переход **«Узнать подробнее»**, в начале профиля и меню **«Ещё»** — **«Помощь и объяснения»**. Отдельный маршрут `#/help` содержит пять разделов и 12 вопросов на расширяемых данных. Аккордеоны работают с клавиатуры. «Назад» восстанавливает прежний экран и позицию окна/родительских прокручиваемых контейнеров, включая перезагрузку справки. Место возврата хранится только в sessionStorage текущей вкладки, проверяется и удаляется после выхода из справки; при недоступном хранилище остаётся безопасный возврат на Главную.

Палитры:

| Тема | Фон | Карточки | Текст | Акцент |
| --- | --- | --- | --- | --- |
| Светлая | #F7F8F4 | #FFFFFF | #252C26 | #52785B |
| Тёмная | #1D2420 | #29332C | #E6EAE3 | #91B59A |

Тема восстанавливается до отображения страницы, чтобы избежать светлой вспышки при загрузке тёмного оформления. Старые настройки «системная»/«комфортная» безопасно переходят в светлую. На странице есть только две темы; никаких автоматических изменений по настройкам устройства. Выбор находится только в **Профиль → Настройки → Оформление**: две компактные кнопки **«Светлая» / «Тёмная»** применяют настройку сразу и сохраняют её в действующем браузерном хранилище. На телефоне профиль открывается через **«Ещё» → «Профиль»**. В шапке, меню «Ещё» и концентрации переключателей темы больше нет.

**Концентрация — настройка текущего экрана**, а не отдельный маршрут. Кнопка **«Фокус»** в шапке включает её в заданиях и открытой теме/конспекте; видимая кнопка «Выйти» отключает. Ответ, проверка, раскрытый разбор, черновик самооценки и прокрутка сохраняются. Переход между заданиями не отключает режим. Лишняя навигация и игровой отклик скрываются; XP и серии продолжают рассчитываться. В конспекте скрыты служебные подписи, цепочка навигации и второстепенные переходы: учебный текст, формулы, примеры и типичные затруднения остаются. Сам каталог теории работает в обычном режиме. Концентрация использует выбранную в профиле тему; кнопка выхода находится в обычной шапке и прокручивается вместе со страницей.

Onest сохранён. Обычный текст — около 17–18 px, условия — 20 px, теория — 18 px на телефоне и 20 px от ширины 768 px; доступны режимы «Обычный / Крупный / Очень крупный». Нужный select под **«Материалы к номеру»** имеет 52 px высоты, 18 px/600, радиус 12 px и горизонтальные отступы 16 px для обеих частей ОГЭ/ЕГЭ. Это изменение относится к select, а не карточкам XP. Выпадающие пункты используют системный интерфейс браузера; их внешний вид в Safari определяется iPadOS.

## Напоминания о перерывах

Бесплатная настройка профиля: **2 часа по умолчанию / 1,5 часа / выключено**. Через 15 минут бездействия непрерывная сессия начинается заново; короткое время в фоне не учитывается. Таймер работает в текущей открытой вкладке и не является облачным расписанием.

При достижении времени уведомление лишь ставится в очередь. Оно появляется после следующей проверки ответа, подтверждения самооценки или перехода. Во время ввода и чтения не открывается модальное окно, фокус и прокрутка не перемещаются. Уведомление можно закрыть; никаких блокировок, OS-уведомлений или XP за само открытие приложения нет.

## Free и Premium

Free получает всю опубликованную теорию, доступную практику, проверку, разбор после проверки и игровую мотивацию. **Накопительная учебная статистика скрыта на всех Free-экранах**: нет количества решённых задач/попыток, точности, истории ошибок и освоения тем.

«Прогресс» и «Мой тренер» в Free показывают описание Premium без учебных показателей. Информационная страница содержит проектные тарифы 200–600 ₽/мес., без покупки и оплаты.

Демонстрационный Premium включается только для разработки:

```bash
NEXT_PUBLIC_ENABLE_PREMIUM_DEMO=true npm run dev
```

Затем: **Профиль → Режим для разработчика**. После перезагрузки снова Free. В production-публикации переменная выключена. Это клиентская демонстрация, а не защищённая подписка.

В демо-Premium работают локальные результаты, попытки, ошибки и темы. Простой тренер отмечает тему после минимум трёх проверок при минимум двух ошибках. Это прозрачное правило, а не диагноз, полноценный учебный план или AI. Интервальное повторение и адаптивная диагностика остаются следующим этапом.

## Хранение и приватность

Данные остаются в localStorage этого браузера; не отправляются на сервер. Храним только настройки, ответы, события проверок/просмотра решения, каталог, черновики и игровой журнал. Паролей и персональных идентификаторов нет. Между устройствами данные не переносятся, удаление данных Safari их уничтожает.

- `tochka-learning-v2`: схема **v3** с игровым журналом v2, атомарная запись учебных событий, самооценок и XP, миграция прежней v2 и `tochka-demo-progress-v1` без выдуманного XP.
- `tochka-practice-v1`: версия 1, каталог, сессии, ответы, ID проверок и состояние решения.
- `tochka-catalog-scroll-v1`: версия 1, координаты окна и прокручиваемых контейнеров с безопасными локаторами.
- `tochka-help-origin-v1`: временный sessionStorage текущей вкладки, только внутренний маршрут и координаты возврата; удаляется после выхода из справки.

Повреждённые записи проверяются, опасные контексты отбрасываются. При недоступном хранилище приложение предупреждает о возможной потере последних изменений. Профиль позволяет удалить локальные данные. Это не резервная копия и не серверная защита Premium.

## Запуск и сборка

Нужен Node.js 22 LTS. Ручное редактирование файлов не требуется.

```bash
npm ci
npm run dev
```

На компьютере открыть http://localhost:3000. В облачной среде открыть Preview / Ports → **3000**, если среда предоставляет эту возможность. `localhost` на iPad означает сам iPad, а не удалённый сервер.

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

Для GitHub Pages:

```bash
npm run build:pages
```

Получится `out/` с `.nojekyll` и base path `/tgminiapp-ege/`. Hash-навигация поддерживает прямые ссылки без серверных маршрутов. Команда только собирает файлы, сама ничего не публикует.

## Обновление через GitHub

Адрес проекта: https://booshish.github.io/tgminiapp-ege/

Поддерживаются два существующих варианта публикации:

1. **GitHub Actions:** Settings → Pages → Source → GitHub Actions. Workflow `.github/workflows/pages.yml` при обновлении `main` устанавливает зависимости, проверяет линтер, типы, тесты и собирает сайт, затем публикует Pages-артефакт. Статус — https://github.com/booshish/tgminiapp-ege/actions .
2. **Готовая ветка:** Settings → Pages → Deploy from a branch → `gh-pages` → `/(root)`. Ветка содержит содержимое `out`, а не исходники. При обновлении готовой ветки сайт пересобирается Pages.

Настройки Pages — свойство репозитория, их нельзя изменить одной лишь записью файлов. При недоступном GitHub API можно отправить исходники и готовую ветку, но нельзя достоверно проверить завершение публикации. Не присылайте токены или пароли в чат.

## Проверки и границы этапа

### Выбор темы только в профиле

Использован уже существующий раздел **«Настройки → Оформление»** с двумя компактными вариантами. Удалены дублирующие кнопки из шапки, меню и концентрации, а также их обёртки и CSS. Сохранение в `tochka-learning-v2` и ранняя инициализация темы до отображения страницы не менялись: первый визит светлый, выбор пользователя сохраняется независимо от темы ОС. В концентрации осталась кнопка **«Выйти»**, оформление берётся из профиля.

Повторный аудит текущей теории не выявил новых объективных дефектов длинного текста. На ширинах 1032/1376 px определения, абзацы, шаги примеров и списки уже используют **20 px / 500 / 1,65**, колонку до **640 px**, промежутки 20 px; заголовки разделов — 24 px/700, примеров — 22 px/700. На iPhone 390 px сохранены **18 px / 500 / 1,6**, ширина 312 px и промежутки 14 px. Текст выровнен влево. Геометрия светлой и тёмной тем совпадает, минимальный измеренный контраст обычного текста выше 4,5:1. Шрифт, палитры и параметры чтения не менялись ради формального изменения: причин связывать дискомфорт именно с ними не установлено.

Проверены 12 состояний теории/обзора в обеих темах на 390/1032/1376 px: без масштабирования, фильтров, прозрачности и горизонтального переполнения страницы. Загруженный Onest с кириллицей подтверждён в браузере; минимальный контраст проверенных текстовых ролей — 5,47:1 в светлой и 6,95:1 в тёмной теме. Тестовые длинная формула и таблица прокручиваются локально.

Браузерная регрессия в Chromium: 320/390/1032/1376/1440 px, восемь разделов, отсутствие переключателя вне профиля, обе темы, светлая по умолчанию при тёмной ОС, сохранение после перезагрузки/новой вкладки и синхронизация между вкладками. Черновик, проверка, XP и серия пережили смену темы, концентрацию и переходы без повторного начисления. Axe не обнаружил нарушений в проверенных профиле и задаче в концентрации; ошибок JavaScript и загрузки ресурсов нет. Физический Safari/iPad не запускался.

Для текущего изменения успешно выполнены `npm test` (102/102), `npm run lint`, `npm run typecheck` и `npm run build:pages`.

Файлы текущего этапа: `src/components/study-app.tsx` (удаление дублей), `src/components/appearance.css` (очистка обёрток и размещение выхода), `src/components/screens/profile-screen.tsx` (пояснение и доступная связь с настройкой), `README.md`; неиспользуемый `src/components/theme-toggle.tsx` удалён. Бизнес-логика заданий, XP, серий, самооценки, подписки и хранилища не изменена.

### Первая доработка чтения теории на планшетах

Аудит выявил конкретное отличие: при размерах 1032×1376 и 1376×1032 обычный абзац занимал **802 px**, в концентрации — **734 px**, при шрифте 18 px и интервале 1,6. Это параметры вёрстки, а не доказанная причина усталости глаз. У текста и его родителей не обнаружены `scale`, прозрачность, фильтры, увеличенный межбуквенный интервал или выравнивание по ширине. Встроенный переменный Onest содержит кириллицу, включая Ё/ё, и настоящие веса 100–900; Chromium подтвердил использование загруженного шрифта.

От 768 px открытые темы и конспекты используют центрированную колонку текста до **640 px**, размер **20 px/500**, интервал **1,65** и промежутки между абзацами **20 px**. Крупный и очень крупный режимы — 22/24 px. На iPhone 390 px сохранены прежние 18 px, интервал 1,6, абзацы 14 px и ширина текста 312 px (316 px в концентрации). Другие страницы и карточки XP не сужены. Цветовые палитры и механика обучения не менялись.

В Chromium проверены 60 сочетаний: ширины 390/768/1032/1376/1440 px, три размера текста, обе темы, концентрация включена/выключена. Дополнительно проверены восемь состояний шапки и контраста: переключатели находятся в потоке документа, уходят при прокрутке, тема сохраняется после перезагрузки, концентрация сохраняет прокрутку. Минимальный измеренный контраст обычного учебного текста — **5,47:1** в светлой и **8,27:1** в тёмной теме; Axe не обнаружил нарушений в этих состояниях. Ошибок JavaScript не обнаружено. Длинная формула и широкая таблица проверены отдельными тестовыми вставками: прокрутка локальная, ширина страницы не растёт. Опубликованных таблиц в текущей библиотеке нет.

После изменений успешно выполнены `npm test` (102/102), `npm run lint`, `npm run typecheck`, `npm run build:pages` и `git diff --check`.

Изменены: `src/components/screens/theory-screen.tsx`, `src/components/theory-screen.css`, `src/components/study-app.tsx`, `src/components/appearance.css`, `README.md`. Настройки тем, переключение концентрации и данные пользователя используют прежнюю логику.

Физический iPad и Safari в этой среде недоступны. На настоящем iPad нужно оценить чтение одного длинного конспекта в течение **5–10 минут** в обеих ориентациях при сопоставимой яркости и освещении; отдельно проверить удобство формул, смены темы и выхода из концентрации. Устранение субъективного дискомфорта без такой проверки не подтверждено.

Новые тесты также проверяют строгие серии, старые события, три размера текста, две темы, все настройки перерывов, безопасный таймер и семь сценариев восстановления места возврата из справки. Браузерные проверки выполнены в Chromium: 320/390/768/1024 px, очень крупный текст, клавиатура, темы, фокус, точная прокрутка, справка и перезагрузка; проверка Axe не обнаружила нарушений в проверенных состояниях. Таймер дополнительно проверен с виртуальным продвижением двух часов: уведомление ждёт следующей проверки. Это не физический iPad, Safari или Telegram WebView.
