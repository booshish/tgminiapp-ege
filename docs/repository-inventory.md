Срез перед реализацией: `ca6389a` (рабочая ветка `work`). Приложение уже существует; это Next.js 15 / React 19 / TypeScript, статический экспорт для GitHub Pages. Исходные пользовательские данные находятся в браузере, сервера аккаунтов нет.

## Материалы ФИПИ

В доступных каталогах `/workspace/library-files`, `/workspace/shared/downloads`, в репозитории и при поиске ZIP/PDF в `/workspace` и `/tmp` не обнаружено шести архивов из сообщения. Идентификаторов вложений для скачивания в сообщении нет. Фактически доступно **0 из 6 ZIP и 0 из 24 ожидаемых PDF**.

Отсутствуют `ma_9_2025.zip`, `ma_9_2026.zip`, `ma_9_2027.zip`, `ma_11_2025.zip`, `ma_11_2026.zip`, `ma_11_2027.zip`. Дубль `ma_9_2027(1).zip` тоже не обнаружен. Это отсутствие исходников, а не ошибка чтения конкретного PDF. Имена PDF внутри архивов пока неизвестны.

Отдельно от отсутствующих вложений прочитаны через веб-доступ копии спецификаций ОГЭ, ЕГЭ базы и профиля 2027 года, а также базы 2026. На [официальном индексе ЕГЭ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) и [индексе ОГЭ](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory) материалы 2027 обозначены проектами; на титульных страницах копий также есть этот статус. Побайтовое совпадение копий с отсутствующими архивами не проверено. Это не обработка приложенных ZIP и не окончательно утверждённые требования.

Матрица `exam-requirements.json` содержит конкретные физические и печатные страницы для фактов из этих копий. Проект 2027: ОГЭ — 25 номеров, 31 первичный балл, 235 минут; база — 21/21/180; профиль — 20/33/235, в том числе 13 кратких и 7 развёрнутых ответов. Добавлены все 66 строк обобщённых планов с кодами содержания/требований и шкалами максимума. Кодификаторы и критерии конкретных заданий демоверсий не прочитаны; их значения остаются неизвестными. Тексты самих демонстрационных задач не копировались.

В копии проекта профиля обнаружено противоречие сводных распределений сложности: раздел 7 и итог приложения дают разные количества базовых/повышенных заданий. Конфликт явно сохранён в матрице; для разрешения необходима проверка канонического документа/утверждённой редакции. В изменениях проекта указаны новая вероятностная позиция №6, краткая финансовая №13, развёрнутая модель №17 и новая нумерация. Прошлогодний 19-номерный вариант нельзя обозначать полным вариантом профиля 2027.

Проекты ОГЭ и базы сообщают об отсутствии структурных изменений к 2026; спецификация базы 2026 сообщает то же к 2025. Это отдельно помеченные заявления документов, а не выполненное сравнение всех 24 PDF. Полная проверка 2025–2027 всё ещё заблокирована отсутствующими вложениями.

Прочитанные копии: [ОГЭ 2027, спецификация](https://examlab.ru/fipi/oge-2027-matematika-specifikaciya.pdf), [ЕГЭ база 2027, спецификация](https://examlab.ru/fipi/ege-2027-matematika-baza-specifikaciya.pdf), [ЕГЭ профиль 2027, спецификация](https://examlab.ru/fipi/ege-2027-matematika-profil-specifikaciya.pdf), [ЕГЭ база 2026, спецификация](https://pro-schools.ru/fipi/ege/spec/2026/ma-11-ege-2026-spec-bazovyy.pdf). Из них извлечены факты структуры, а не тексты задач. Права на распространение полных документов не установлены; сами документы в публичные файлы приложения не добавлены.

Повторяемая инвентаризация и безопасная распаковка после получения вложений:

```sh
node scripts/exam-materials.mjs --input-dir /path/to/archives --matrix docs/exam-requirements.json --check
```

CLI проверяет CRC всего архива, ограничения распаковки, опасные пути, символические ссылки, шифрование; считает все PDF, сохраняет SHA-256, извлекает текст по страницам и фиксирует титульные признаки года/экзамена/уровня/вида документа/слова «Проект». Выявленные признаки требуют содержательного просмотра: автоматическая классификация не устанавливает утверждение документа и не заполняет требования догадками. PDF и полные извлечённые тексты сохраняются только в локальном scratch, не в публичных ресурсах. `--check` завершается ошибкой при неполном наборе.

## Навигация и экраны

Один вход `src/app/page.tsx` → `src/components/study-app.tsx`. Маршруты разбираются из hash в `src/lib/navigation.ts`: `home`, `catalog`, `tasks`, `theory`, `trainer`, `progress`, `profile`, `premium`, `help`, `favorites`, `mistakes`, `review`, `mock`. Название `catalog` и `tasks` в меню — «Задания», `mock` — «Учебный вариант». Контекст включает экзамен, предмет `math`, уровень `base/profile`, часть, номер, тему, прототип, стабильный ID задачи и ID сессии.

`src/lib/exams.ts` задаёт три версии 2026: ОГЭ (25 номеров, часть 1: 1–19), ЕГЭ база (21 номер, в исходном срезе выключена), ЕГЭ профиль (19 номеров, часть 1: 1–12). Статус правил исходного проекта — `project-config`; подтверждения актуальности 2027 нет. `exam-scores.ts` содержит отдельную версионированную сетку XP/первичных баллов. Номерные структуры и баллы нельзя менять на месте с теми же ID: старые события валидируются по метаданным версии.

## Банк, теория и проверка

`src/lib/tasks.ts` объединяет прежние задачи и авторские семейства `content/oge-bank.ts`, `ege-bank.ts`, `challenge-bank.ts`. На исходном срезе задокументированы 432 доступные задачи и 16 сохранённых задач базы для истории; количественные отчёты после правок формируются заново. Поле `examNumber: null` обозначает фундаментальное упражнение, а не номер экзамена. Доступность задаётся фильтром версии/уровня, а не порядковым индексом.

`src/lib/theory.ts` содержит статьи и их применимость к версиям/частям/номерам. `math-formula.tsx` рендерит LaTeX через KaTeX, с существующей поддержкой локальной прокрутки длинных формул. Счётчик наличия статьи сам по себе не доказывает полноту всех подтем кодификатора.

Автоматическая проверка `checkTaskAnswer` различает числовой ответ и множество ответов, нормализует ввод и проверяет валидность. Ответ `self` — развёрнутая работа для самопроверки; это не автоматическая проверка доказательства. `selfCheckNotes` — авторские ориентиры, а не официальные критерии ФИПИ.

## Учебные варианты

`src/lib/mock-exam.ts`, `src/hooks/use-mock-exam.ts`, `screens/mock-exam-screen.tsx` уже обеспечивают полный набор доступных номеров, таймер по абсолютному deadline, ответы/черновики, восстановление сессии, завершение, отдельные краткие результаты и самооценку развёрнутой части. ОГЭ 1–5 выбираются из одной `sharedConditionId`. Исходная длительность 235 минут прямо обозначена учебной настройкой. Полный по конфигурации проекта вариант ещё не является подтверждённым вариантом по спецификации 2027 года.

## Пользовательские данные и совместимость

| Данные | Основной ключ | Правила исходного проекта |
| --- | --- | --- |
| Учебные события, настройки, XP, серии | `tochka-learning-v2` (схема 3) | Единый журнал; миграция прежнего `tochka-demo-progress-v1`; тема, размер текста, концентрация и напоминания в той же записи |
| Практика, позиции, черновики | `tochka-practice-v1` (схема 2) | Общий `taskStates[id]`; контекст экзамен/предмет/уровень/часть/номер/тема/прототип; стабильный `lastTaskId`; миграция схемы 1 |
| Избранное | `tochka-study-tools-v2` (схема 2) | Миграция `tochka-study-tools-v1`, стабильный ID материала, синхронизация между вкладками |
| Варианты | `tochka-mock-exams-v1` | Сессии, активная попытка, deadline, ответы, результаты, самооценки и опубликованные задачи |
| Прокрутка каталога | `tochka-catalog-scroll-v1` | Отдельный ограниченный снимок позиции |

Ошибки, прогресс и интервальные повторения выводятся из канонических учебных событий; это не параллельные записи XP. `learning-mutations.ts` и `gamification.ts` не должны повторно награждать одну задачу: XP хранятся с идентификаторами событий и привязкой к задаче. Win Streak учитывает только первую автоматическую проверку уникальной задачи первой части; повторная проверка старой задачи и самооценка второй части серию не меняют. При повторной отправке результатов варианта используются устойчивые request ID и `publishedTaskIds`.

При обновлении контента сохраняются существующие ID, версии, ответы и порядок старых задач; новые задачи добавляются к сохранённым сессиям без сброса позиции. Нечитаемые локальные записи не должны затираться пустыми. Между устройствами синхронизации нет.

В исходном `study-tools.ts:isAvailableTask` жёстко допущены ОГЭ и ЕГЭ профиль. При включении базы этот фильтр необходимо согласовать с реальной доступностью, иначе ошибки и избранное базы не будут работать.

## Доступ и адаптация

Практика, теория, ручные ошибки, избранное и базовый учебный вариант доступны бесплатно. Premium относится к аналитике/авторекомендациям по существующей модели; серверная оплата и активация не подключены. Цены/подписки не являются частью этой работы.

Существующие телефонные правки ограничены `max-width: 767px`; от 768 px сохраняется планшетный интерфейс. Нужны ширины 320–430 px, кнопки не меньше существующих 44 px, отсутствие горизонтальной прокрутки всей страницы, локальная прокрутка формул, Onest и обе темы. Стили `catalog-screen.css`, `mock-exam.css`, экранные и мобильные CSS уже входят в приложение; радикальная переделка не требуется.

## Проверяемость и права

Есть `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `npm run build:pages`, `content:check`, отчёты и независимые математические тесты семейств. Результаты текущего запуска фиксируются в итоговом отчёте; сведения прежнего README не считаются запуском проверок сейчас.

Тексты демоверсий не публикуются. Общедоступность ФИПИ не устанавливает лицензию. Новые учебные тексты/задачи должны быть оригинальными, с реестром происхождения и честным статусом проверки. Чужие тренажёры не использовались как источник текстов, решений или иллюстраций.
