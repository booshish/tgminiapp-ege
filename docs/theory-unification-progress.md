# Единая теория и хлебные крошки — 4 ноября 2026

## Реализовано

- Сохранён единый опубликованный набор: 108 материалов (математика — 73, информатика — 31, физика — 4). Все ID, materialId, старые алиасы, исходные разделы, примеры и сведения проверки совпадают с контрольной точкой `6a5d283`.
- Метаданные — представление над существующим материалом: предмет, раздел, подраздел, применимость к экзамену/уровню, известные номера, общие разделы, экзаменационные пояснения и связь с тренировкой. Копий статей для разных экзаменов не создаётся.
- Восемь общих математических материалов доступны ОГЭ, ЕГЭ базе и профилю. Добавлены короткие авторские пояснения по применению на выбранном экзамене; они не объявлены официальными критериями. Общая часть и примеры остаются одними и теми же.
- Один предикат применимости используется в списке и при прямом открытии статьи. Базовые и профильные экзаменационные материалы не смешиваются. Поиск, часть и номер работают совместно с новым фильтром раздела.
- Карточки и статьи показывают применимость, раздел и известные номера. Для общей темы без подтверждённых номерных связей номера не выдумываются.
- На статье: семантические `nav` / `ol`, текущая статья с `aria-current="page"`. На широком экране: «Теория → Предмет → Раздел → Статья»; на телефоне — «← Раздел». Экзамен остаётся в отдельных метках. Предыдущие уровни открываются одним нажатием через существующую навигацию.
- Поиск, часть, номер и раздел сохраняются в проверяемом sessionStorage-кэше отдельно для каждого экзамена, предмета и математического уровня. Неизвестная версия не перезаписывается; при недоступном хранилище показывается предупреждение, а чтение остаётся доступным.
- Возврат из статьи использует существующий `useCatalogScroll` с отдельным ключом: сохраняются реальные позиции прокручиваемых предков, в том числе `main-content`. Работает после обновления внутри статьи. Хлебная крошка раздела меняет только раздел, остальные фильтры сохраняются; новая подборка может сбросить позицию как обычное изменение фильтра.
- Переход в тренировку из прямой ссылки теории использует выбранный экзамен статьи, а не несвязанный ранее сохранённый экзамен практики.
- Теория по-прежнему бесплатна. Мобильная навигация, подписка, банк заданий, XP, черновики и закладки заданий не менялись.

## Ограничения

- Реальный Safari и физические iPhone/iPad недоступны: проверка на Chromium-эмуляции не заменяет проверку WebKit и устройства.
- Это не создание полного курса. Для русского, биологии, химии и обществознания готовых опубликованных конспектов в исходном наборе нет: показывается честное пустое состояние, без подстановки математики. Скрытая физика не включалась в пользовательский выпуск.
- У восьми общих материалов школьные разделы указаны явно. Остальные сохраняют честный общий раздел «Экзаменационные темы»: детальная предметная рубрикация требует отдельной содержательной редакции, не делалась по догадке.
- Состояние списка хранится локально в текущем браузере/вкладке; облачная синхронизация фильтров не добавлялась. Общая часть исходных статей не переписывалась и не объединялась автоматически по похожим заголовкам.
- Целевые привязки сохраняют существующий статус проекта 2027, не выдаются за окончательно утверждённую спецификацию.
