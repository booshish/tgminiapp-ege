Дата: 21 октября 2026. Исходная версия для сравнения: `77ccc62`.

## Что обнаружено

- Общие правила `.app-shell` перекрывали часть прежних мобильных размеров: условие задачи получало 20 px, кнопки — 17 px, подписи — 15,5 px.
- Карточки главной сохраняли минимальную высоту 224 px; номерные карточки каталога — 185–205 px. Многие отступы оставались 22–36 px даже на телефоне.
- В заданиях формула находилась в двух вложенных блоках с собственными отступами и минимальной высотой внешнего блока 130 px.

Это подтверждённые особенности вёрстки. Они не являются установленной медицинской причиной дискомфорта при чтении.

Сетка главной при увеличении текста может перейти с двух колонок на одну. Шапка допускает перенос, длинные слова не расширяют страницу. Уменьшение всей страницы через `zoom` или `transform: scale()` не используется.

## Формулы и теория

Неделимая формула имеет собственный горизонтальный скролл. Внутренний KaTeX-блок получает естественную ширину и выравнивание влево: начало длинного выражения не уезжает в недоступную отрицательную область. Страница не скрывает переполнение искусственным `overflow-x: hidden`. Формулы доступны с клавиатуры; в теории при фактическом переполнении остаётся явная подпись о прокрутке.

Убраны повторные внутренние отступы формулы в задании. «Сохранить» по-прежнему находится внутри карточки краткого и полного конспекта, отдельно от ссылки возврата. Служебный блок «О материале» раскрывается; учебный текст и примеры не сокращались.

## Ограничения

Проверки выполнены в Chromium. Настоящие Safari на iPhone/iPad, экранная клавиатура iOS и Telegram WebView в среде недоступны. Уменьшение высоты окна проверяет компоновку при клавиатуре, но не заменяет тест iOS. На устройстве стоит проверить чтение, ввод ответа, прокрутку длинной формулы и системное увеличение текста. Утверждения о комфорте глаз по одним CSS-размерам не делаются.

Проверены публичные Free-экраны Premium-разделов и тарифов; реальные платные аккаунты и серверная подписка в проекте отсутствуют. Бизнес-логика этим обновлением не менялась. Локальные учебные данные остаются в прежних хранилищах браузера.

Для запуска: `npm ci` → `npm run dev` → http://localhost:3000. Сборка для GitHub Pages: `npm run build:pages`; подробности публикации — в README.
