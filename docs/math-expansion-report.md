# Правомерное наполнение математики — выполненный этап

Дата: 21 октября 2026. Исходная версия: `ca6389adcb94c126b356e6e15fdf24743af15a59`.

## Результат и границы

**Полное покрытие ОГЭ, ЕГЭ базы и профиля не достигнуто.** Это рабочее улучшение существующего приложения и редакционного процесса. Среда отклоняет оба официальных указателя ФИПИ с CONNECT 403. Локальных спецификаций/кодификаторов нет. Согласно блокирующему условию задания новые официальные номера, баллы, длительность и полные варианты не утверждены; база не включена. Сохранена прежняя авторская практика по предварительной карте.

Всего 52 уникальные статьи: общие восемь используются повторно. Новых статей нет. В этих восьми улучшены объяснения: **+16 разобранных примеров, +16 контрольных вопросов, 8 алгоритмов и итогов**. Теперь разобранных примеров 120 вместо 104. Ответы контрольных вопросов и их формулы раскрываются отдельно. Это учебная самопроверка без XP или регистрации новой попытки.

Создано **32 самостоятельных фундаментальных упражнения**, по четыре разных конструкции для дробей, десятичных чисел, процентов, линейных и квадратных уравнений, степеней/корней, геометрии, вероятности. У всех подробные решения, стабильные ID и вычислительные проверки. Они остаются **неопубликованными черновиками**, без экзаменационных номеров, баллов или заявления о соответствии ФИПИ. Их нет в публичном банке и клиентских JS-файлах.

[Машинная матрица](math-coverage-matrix.json) и [таблица каждого номера](math-coverage-matrix.md) отделяют имеющуюся проектную конфигурацию от официальных полей `null`. Ни один из 44 доступных номерных разделов пока не достиг 20 задач. До этой цели по прежней предварительной карте недостаёт 266 задач ОГЭ, 189 профиля и 420 для неопубликованной базы. Эти количества не заменяют сверку актуальной официальной структуры. Особенно нужны новые подтипы ОГЭ №1–5, геометрии, параметров и развёрнутых задач; существующие числовые варианты не объявляются исчерпывающим разнообразием.

## Что реально изменено

- `source-registry.ts` хранит происхождение, дату проверки, права, атрибуцию и свидетельства. Только самостоятельный контент проекта имеет зафиксированное основание для публикации. ФИПИ зарегистрирован для проверки требований; право перепубликовывать его задания не объявляется. Страницы и robots.txt Школково также недоступны; материалы конкурентов не читались для переноса и не импортировались. Обходов ограничений не было.
- `content-publication.ts` отклоняет неизвестные источники, неподходящие/истёкшие права, отсутствие атрибуции, черновики и незавершённую математическую проверку. Фиксированный список ID не позволяет новой записи автоматически получить статус опубликованной.
- `content-review-manifest.json` связывает 448 прежних/архивных задач и 52 статьи с точным SHA-256 содержания. Изменение условия, ответа, решения, рисунка, баллов или статьи требует отдельного обновления редакционного свидетельства. Автоматического пересоздания манифеста при сборке нет. Для прежнего банка записан ограниченный объём автоматических проверок; это не доказательство независимой экспертной проверки каждой старой задачи.
- `npm run build` и `build:pages`, а также экспорт seed сначала проверяют происхождение и неизменность проверенного содержания. Новые неподтверждённые материалы не попадают в практику, теорию и новые учебные варианты. Сохранённые старые варианты не удаляются.
- Экспорт seed версии 2 содержит существующие экзамены, задачи, теорию, реестр источников и редакционный манифест. Это файл для последующего импорта, не миграция несуществующей БД. Исходные ID/порядок задач и ID материалов сохранены, пользовательские хранилища не очищались.
- Отдельный редакционный экспорт новых упражнений формирует восемь тематических файлов, индекс и SHA-256. Он заново запускает математические тесты, не перезаписывает существующую папку и не сохраняет черновики в публичную директорию приложения. Публичный старый банк пока остаётся в существующей клиентской архитектуре; полноценная сетевая загрузка огромного банка по частям — следующий этап.
- Добавлен инструмент фиксированных версий вариантов: проверка манифеста официальных документов, контрольных сумм, числа/порядка номеров, баллов, общих условий, допустимости самопроверки, прав и ревизий задач. При неполных данных он не создаёт частичные варианты под видом полных. Сейчас все три направления заблокированы, реально опубликованных фиксированных полных вариантов — **0 из требуемых 15**. Работа инструмента проверена синтетическими фикстурами; они не опубликованы и не считаются учебным контентом.
- Во второй части пользовательская подпись приведена к «Самопроверка». Внутренние ключи `self_assessment`/`self_assessed` сохранены ради совместимости. Механика XP/серий, цены, Premium, хранение черновиков и навигация не перерабатывались. CSS добавлен только для новых вопросов внутри конспектов.

## Выполненные проверки

- `npm test`: **289/289**, без пропусков. После добавления полного реестра в seed дополнительно прошли 9 затронутых тестов экспорта и интеграции.
- `npm run lint`, `npm run typecheck`, `npm run content:check`, `git diff --check`: успешно.
- `NEXT_PUBLIC_ENABLE_PREMIUM_DEMO=false npm run build:pages`: успешный статический экспорт, первая загрузка JS около 331 kB по отчёту Next. Черновики и редакционные SHA-манифесты в клиентский JS не импортированы.
- 32 новых упражнения проверены отдельными вычислительными оракулами: точная арифметика, подстановка, области определения, полнота корней, геометрические вычисления, перебор вероятностных исходов, правильные и неправильные ответы, строгий KaTeX. Все 16 новых примеров и 16 ответов конспектов проверены вычислительно и отдельным математическим обзором. Это не внешняя предметная экспертиза.
- Выполнены `content:stage` и `content:seed`: экспорт 32 черновиков в 8 файлов и полного каталога; детерминированность, права, контрольные суммы и запрет перезаписи проверены тестами. Ни один экспорт не изменяет пользовательские данные.
- `exam:release:check` **ожидаемо завершился кодом 1**: нет подтверждённых документов для всех трёх направлений. Это требуемая блокировка, а не успешно пройденная официальная сверка.
- Chromium, готовая production-сборка: **144/144 состояния** (8 конспектов × 2 темы × ширины 320/360/375/390/430/768/1032/1376/1366). Нет горизонтального скролла страницы и ошибок KaTeX; в 54 состояниях проверена фактическая локальная прокрутка длинных формул. Все 288 раскрытий вопросов доступны с клавиатуры; цели нажатия от 44 px. Четыре выборочные проверки Axe — 0 нарушений.
- Для восьми конспектов проверены сохранение/удаление закладки с reload и сохранение открытого материала/раскрытого вопроса при концентрации. Тема остаётся в профиле. Текст на телефоне — прежние 16px/400/1,6; на планшете — 20px/500/1,65 и колонка до 640px.
- Проверены реальные ответы: два новых верных → серия 2; первая ошибка → 0; следующая новая верная → 1; повторные проверки и исправление прежней задачи не дублируют серию/XP. Возврат из теории/профиля, позиции №7/№12, разделение ОГЭ/ЕГЭ, reload, черновики, концентрация и сохранение повреждённой/неизвестной схемы с предупреждением прошли.
- Самопроверка второй части 3→4→2 даёт ровно 3→4→2 XP, не меняет серию; повторное подтверждение отключено, оценка и текст решения переживают reload.
- На 320/390/1032/1376px в двух темах проверены сокрытие решения до проверки, раскрытие после ошибки, переходы и сохранение ответа, выбор №19 учебного варианта, предыдущий/следующий, reload и отсутствие переполнения.
- **24/24 снимка** Главной, Избранного, Прогресса и Тренера на 768/1032/1376px, в двух темах, попиксельно совпали с исходной статической сборкой. Содержимое расширенных конспектов закономерно стало длиннее. Не утверждается попиксельное сравнение всех страниц.

При первом браузерном запуске локальный сервер был остановлен (`ERR_CONNECTION_REFUSED`). После его перезапуска весь сценарий выполнен заново; приведены результаты завершённых проверок. Ошибок JavaScript/HTTP в успешных запусках не обнаружено. Настоящие Safari/iPhone/iPad и субъективный комфорт чтения не проверены. На устройстве полезно оценить 5–10 минут чтения при привычной яркости.

## Что необходимо для следующего этапа

1. Получить и проверить по одному комплекту спецификации, кодификатора и демонстрационных критериев ОГЭ, ЕГЭ базы и профиля для выбранного года. Нынешний проект настроен на 2026; переход на 2027 требует отдельной реальной сверки документов. [Точные источники и недостающие документы](math-sources-audit.md).
2. Зафиксировать редакционную сверку, даты, SHA-256 и применимость критериев. Официальные PDF используются как доказательства требований, по умолчанию исключены из Git; открытость PDF не разрешает перепубликовывать его задачи.
3. Привязать новые самостоятельные материалы к проверенным навыкам, расширять существенные подтипы, провести экспертный просмотр сложной геометрии/параметров. Пропускать через редакционный список и отпечатки только проверенную редакцию.
4. Заполнить каждый подтверждённый номер, затем сформировать пять стабильных полных вариантов каждого направления и проверить их в существующем учебном интерфейсе. Пока этого нет, не объявлять полное покрытие.
5. Для большого банка добавить загрузку нужных тематических/экзаменационных частей. Сейчас 32 черновика не увеличивают публичный пакет. Синхронизация между устройствами, серверная защита XP и Premium требуют отдельного backend; платежи не подключались.

## Запуск и публикация

```sh
npm ci
npm run dev
npm test
npm run lint
npm run typecheck
npm run content:check
npm run content:matrix
npm run content:stage -- /tmp/tochka-foundation-review-02
npm run content:seed -- /tmp/tochka-content-v2.json
npm run exam:release:check # сейчас ожидаемо блокирует официальный выпуск
NEXT_PUBLIC_ENABLE_PREMIUM_DEMO=false npm run build:pages
```

`npm ci` приведён как инструкция чистой установки, не как выполненная повторная установка в этом запуске. Проверки выполнялись с установленными зависимостями проекта. GitHub Pages публикует содержимое `out/` с base path `/tgminiapp-ege/`; маршруты остаются hash-маршрутами. Публичный адрес: https://booshish.github.io/tgminiapp-ege/ .
