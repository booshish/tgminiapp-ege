# Обновление «Точка Premium»: реализация и проверки

Дата: 21 октября 2026 года.

## Что обнаружено

Проект — существующее статическое приложение Next.js / React / TypeScript. Раньше экран Premium содержал большую таблицу предварительных цен; отдельной модели календарных подписок не было. Пользовательские настройки и учебная история сохраняются локально. Авторизация, БД, платёжный провайдер и защищённые права отсутствуют. Реально поддерживается один предмет — математика; ОГЭ и ЕГЭ не считаются двумя предметами.

## Проверки в Chromium

Проверены реальные действия в существующем приложении:

- Самостоятельный правильный ответ в бесплатной практике дал ровно 1 XP. Затем переходы Premium → профиль → практика, перезагрузка и просмотр решения сохранили ответ и не добавили повторный XP.
- Переключение месячных и осенних сезонных цен, подпись стоимости всего периода, раскрытие блока разработки.
- Все кнопки оплаты/trial отключены; набор на четыре предмета нельзя выбрать при одной доступной математике.
- Профиль остаётся Free. Разделы глубокой аналитики и тренера закрыты; изучение тарифов не выдаёт подписку и не меняет учебные события.
- Тёмная тема выбрана только в профиле и сохранилась после перезагрузки. Кнопка смены темы не появилась в шапке.
- Открытая страница обновила предложение на московской границе Нового года, когда браузер был в часовом поясе Honolulu. При неподтверждённом январском расписании сезонный вариант скрывается.
- Axe: нарушений на странице Premium в светлой и тёмной темах не найдено.
- Адаптивность: **16 сочетаний** 390×844, 1032×1376, 1376×1032, 1440×900; светлая/тёмная темы и обычный/очень крупный текст. Горизонтального скролла и обрезания поля выбора нет; три колонки на широких экранах, вертикальные карточки на телефоне. Проверены точные цены и отключённые покупки во всех состояниях. Axe в шести сочетаниях размеров и тем — 0 нарушений; ошибок JavaScript и загрузки ресурсов нет. Скриншоты просмотрены.

Основной интеграционный сценарий повторно прошёл на готовом `out/`, отданном локальным HTTP-сервером с базовым путём `/tgminiapp-ege/`: правильный ответ → 1 XP → просмотр тарифов/профиля → перезагрузка → сохранённый ответ без повторного XP, Free-разграничение, смена темы, московская граница года и Axe обеих тем. Ошибок JavaScript нет.

Для публикации используются существующие ветки исходников и `gh-pages`; собранные файлы соответствуют проверенному `out/`. Проверить публичный HTTPS-адрес из этой среды нельзя: соединение с GitHub Pages также отклоняется CONNECT HTTP 403. Успешная отправка файлов в GitHub сама по себе не подтверждает завершение обновления на CDN.

## Ограничения и следующий этап

Оплата, фактическая активация trial, автосписания, серверная однократность пробного периода и управление подпиской не подключены. Слоты/замены/статусы реализованы как проверяемая модель и интерфейс для будущего сервиса. Текущий профиль не читает выдуманный Premium из localStorage. Разработческий демонстрационный доступ остаётся отдельным прежним механизмом, выключенным в публичной сборке.

Точные даты окончания основного сезона 2026/2027 оставлены `null`. HTTPS-запросы к официальным источникам блокируются средой с CONNECT HTTP 403; расписание не подтверждено. Сезонные цены осенью можно изучить как пример, но дата и покупка не имитируются. Летний тариф включится по подтверждённой конфигурации сезона.

Для настоящей продажи нужны официальное расписание, авторизация/серверная БД, проверенные сервером котировки и права, транзакционная идемпотентность, защита trial и платёжный провайдер. Подробности — в [модели подписок](subscription-model.md).

Физические Safari на iPad/iPhone и Telegram WebView здесь недоступны. Эмуляция размеров Chromium не заменяет проверку на настоящем устройстве.
