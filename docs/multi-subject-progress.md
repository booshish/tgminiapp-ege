## Конвейер и контрольные точки

- Исходные условия/ключи: `scripts/multi-subject-originals.mjs`. Независимые вычисления и отдельные языковые аннотации: `scripts/release-multi-subject.mjs`. Языковые аннотации не являются независимой экспертной аттестацией; автоматическая проверка структуры её не заменяет.
- Используется **тот же** `releasePilot` → JSONL `importTasks` → staging → immutable shards → metadata index → `ensureTaskPackages`. Release расширен на произвольные партии с сохранением старого индекса, без второго импортёра/банка.
- Первый проход остановлен на одном близком совпадении геометрической задачи. Проверка не ослаблялась: условие заменено другой математической моделью. Продолжение — job `multi-subject-20261026-r2`; found 40, rightsAllowed 40, staged 40, duplicates 0, rejected 0, review 0. Старый checkpoint сохранён локально для аудита.
- `docs/multi-subject-review.json`: отпечатки и evidence; `multi-subject-verification.json`: вычисленные результаты/область QA; `multi-subject-inventory.json`: все 30 связок.
- Повторный release не изменяет уже выпущенные ID: изменение тела с теми же ID блокируется сравнением SHA256. Старые 12 задач остаются в прежних файлах/порядке. Условий/ответов в JS-индекс не добавлено.
- Совместимость: часть 2 русского ОГЭ — **краткие ответы**, поэтому нельзя использовать «part=2» как универсальный признак сочинения. Исправлены guard записи ответов и формат восстановления; математические развёрнутые ответы всё ещё нельзя автопроверять. Просмотр решения сохраняет фактический предмет, а не `math`. Алгоритмы начисления XP/серий, цены и доступ не менялись.

## Границы проверки форматов

Покрыты числа/десятичные/дробные/отрицательные ответы, текст, неупорядоченный набор выбранных цифр, LaTeX и исходный текст синтаксического задания. У новых геометрических задач все необходимые величины даны текстом, обязательной отсутствующей картинки нет. Новые аудио, произвольные изображения/карты, экспертные сочинения и устные ответы **не испытаны и не сертифицированы этим этапом**. Специальный старый renderer прямоугольного треугольника не выдаётся за универсальную поддержку рисунков.

Для продолжения сначала расширять проверенные подтипы небольшими пакетами, отдельно добавлять модели/ресурсы заблокированных предметов. Не переходить к тысячам без этих проверок.
