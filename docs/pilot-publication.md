# Первый опубликованный пакет — 2026-10-26

12 **настоящих новых оригинальных учебных задач**, не нагрузочных фикстур. Предмет — информатика ОГЭ; номера 1, 3, 5, 6, 9, 10, по 2 задачи. У всех условие, однозначный числовой ответ, подробное объяснение, стабильный ID, авторство, экзаменационная привязка и review. Не копии официальных экзаменационных задач, не реальные КИМ. Модель проекта 2027 отмечена в интерфейсе как проект, унаследованные баллы не объявлены официально проверенными.

Новые сторонние экзаменационные материалы: **0**. Из рассмотренных источников ни у одного не подтверждено коммерческое право перепубликации самих задач. Поэтому выбран разрешённый пользователем альтернативный путь. Не утверждается, что информатика имеет больше всего лицензированных чужих задач: их подтверждённое число во всех проверенных кандидатах равно нулю. Информатика выбрана для малого проверяемого пилота (существующая сверенная модель, короткие ответы, без отсутствующих медиа).

## Конвейер

`node scripts/release-task-pilot.mjs` проверяет ключи независимыми исполняемыми алгоритмами, создаёт JSONL и review, запускает **существующий** `importTasks`. Из staging выбираются только записи `staged`. Пробный проход: found 12 / rightsAllowed 12 / staged 12 / duplicates 0 / rejected 0 / review 0. Все разрешения — для собственных материалов проекта, не найденная сторонняя лицензия.

После допуска записываются 6 контентно-адресованных файлов в `public/task-packages` и маленький индекс метаданных в `src/lib/task-package-index.ts`. SHA256 тела каждого shard зафиксирован в этом индексе. `docs/pilot-task-review.json` отдельно хранит отпечатки каждого задания и ссылки на вычислительную проверку.

`task-packages.ts` загружает только выбранный номер/тему либо ранее использованные задачи, проверяет HTTP, SHA256, состав ID и существующий publication gate. Повторные и одновременные запросы объединены; повреждённый пакет не регистрируется, неудачу можно повторить. Задачи дописываются в существующий массив `practiceBank`, не меняя старый порядок/ID. Ответы проверяет прежний `checkTaskAnswer`, не второй алгоритм.

Главная и список номеров не загружают условия. Честный счётчик учитывает маленький metadata index, не создаёт поддельных Task. При открытии номера появляются 3 задачи: 1 старая и 2 новые. Для восстановления сохранений сначала загружаются пакеты по сохранённым ID, затем разбираются черновики/закладки/журнал. Ошибка загрузки не должна приводить к записи пустых сохранений. В parser истории устранено прежнее ограничение только `math`: контекст теперь сверяется с предметом конкретной существующей задачи. Алгоритмы XP/серий не изменены.

## Проверки и продолжение

Совместимость журнала: у нематематической практики раньше UI возвращал вымышленный ID вместо записи события. Теперь используется общий `recordAnswer` и общий обработчик просмотра решения; parser сохраняет фактический предмет. Формулы начисления XP, правила серий и проверка наличия утверждённого scoring rule не менялись. Повторная загрузка не создаёт новых событий и наград.

- Вычисления: информационный объём; перебор целочисленных логических условий; исполнение команд; циклы; перечисление путей графа; позиционное накопление при смене основания. Все 12 ключей совпали; условия и объяснения дополнительно проверены адресно.
- Структура, права и близкие/точные дубликаты проверены существующим импортом.
- Тесты lazy-loader: нулевые запросы без выбора, загрузка только одного номера, объединение запросов, повтор, неизменность старого порядка, отказ при повреждении SHA256, восстановление по сохранённому ID.
- Browser QA: `scripts/test-browser-task-packages.py` открывает и решает все 12 опубликованных задач через production export и проверяет журнал после reload.
- Расширение до 1000 не выполнено: нет разрешённого внешнего набора, массовое тиражирование однотипных новых условий не проводилось. Следующий пакет можно подготовить тем же конвейером; исходники/проверки менять отдельно от уже выпущенных immutable shards.
- Поддержка новых изображений/аудио и происхождения стороннего контента остаётся отдельной задачей. Случайный staging не является public release.

Финальная проверка: `npm test` — **387/387**; lint, typecheck, `content:check`, production `build:pages` и `git diff --check` успешны. Проверка production export: 5 браузерных сценариев нового пакета, все 12 ответов, reload истории/проверенных ответов/закладки, мобильный overflow и отсутствие перезаписи данных при недоступном shard — успешно, ошибок страницы нет. Также прошли 9 существующих сценариев workspace (математика, варианты, предметы, навигация, черновики, темы, тренер). Повторные сборки потребовались для исправлений обнаруженного старого ограничения нематематического журнала; итоговая сборка успешна. Изменений Actions/Pages-настроек нет.
