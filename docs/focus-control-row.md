# Выход из фокуса в строке управления

Причина: exit находился в отдельном topbar выше main-content. Sticky делал эту отдельную шапку доступной при прокрутке, но не выравнивал её с переключателем и позволял содержимому проходить позади неё.

В практике выход теперь передаётся как focusExit в существующую practice-view-controls и вызывает прежний toggleConcentration. В фокусе прежняя пустая шапка скрыта. Основная область занимает 100dvh с существующими safe-area отступами, практика имеет две grid-строки: auto для управления и minmax(0,1fr) для practice-content. Прокручивается только нижняя строка. Поэтому управление остаётся на месте, а текст/формулы/ответы/рисунки физически не рисуются под выходом: это не overlay и не z-index обход. На узком экране flex-wrap разрешает перенос. Остальные страницы фокуса сохраняют прежнюю шапку.

У вложенного scrollport есть постоянный id. Capture viewport дополняется его позицией ПОСЛЕ старых ancestors, чтобы не менять индексы старых сохранений. При смене задачи scrollport сбрасывается вместе с прежними родительскими контейнерами. Хранилища, задания, ID, ответы, XP и проверка не менялись. Адаптивная ширина сохранена; native scrollbar gutter может занимать несколько дополнительных пикселей.

Изменены: practice-workspace.tsx (слот выхода и scrollport), study-app.tsx (размещение прежнего действия и сброс прокрутки), workspace-layout.css (две строки без перекрытия), viewport-position.ts (захват нового контейнера), два адресных браузерных теста. Регрессия taps проверяет вертикальный центр выхода/переключателя, непересечение viewport контента и выхода на 0/50/100% scroll, один tap при сфокусированном ответе, сохранность черновика/reload и проверенного результата. Две темы, 320/375/390/768/820/1024/1440/1920 px, два состояния меню, landscape 1024×768. Solver-width дополнительно проверяет SVG, исходный текст и TSV ресурс в фокусе.

Реальные Safari/iPad и системная клавиатура недоступны; используется Chromium touch emulation, не выдаваемая за реальное устройство. Сетевой доступ к github.io ограничен: подтверждается локальный точный export и удалённый native Pages отдельно.
