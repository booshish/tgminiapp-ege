## Проверка и ограничения

- Численные ответы: отдельный Python — точные дроби, целочисленный перебор, прямой пересчёт позиционных записей и симуляция финансовых операций. Таблицы проверяются по самому TSV, а не только по генераторному ключу: сортировка/частоты, эквивалентное сравнение сумм.
- Русский: 10 отдельных грамматических условий (по 5 на экзамен), адресно проверены формы и остальные варианты. Биология: 3 условия на общие свойства клеток и выводы из описания. Это ограниченный редакционный набор, не автоматическая верификация любых языковых/биологических заданий; внешней экспертной проверки 0. Основные утверждения о клетках согласованы с ранее сохранёнными предметными справками (см. remaining-generators.mjs / клеточные структуры и OpenStax Biology 4.3); чужие условия не переносились.
- Не добавлены сочинения/изложения или фиктивные аудио/рисунки. Структурная проверка ресурсов не равна содержательной проверке всех изображений старого банка. Частичные критерии многобалльных заданий не выводятся из максимума; полный ключ в практике не изображает экспертное оценивание.
- Новые условия классифицированы по собственным узким семействам. Полнота существенных подтипов и индивидуальные коды кодификатора не подтверждены. Полная семантическая/embedding-дедупликация не заявляется: используется прежний точный/лексический near-match gate плюс предметная проверка.
- Исправлен технический предел чтения больших исторических metadata index: git show в редакционном loader допускает 32 MiB вместо неявного 1 MiB. Сравнение старых байтов/ID не ослаблялось.
