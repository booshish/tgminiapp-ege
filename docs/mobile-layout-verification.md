# Мобильные экраны по согласованным макетам

Дата: 21 октября 2026 года. Исходная версия: `c40694b`.

## Область изменений

Обновлено существующее приложение Next.js 15 / React 19 / TypeScript с hash-маршрутизацией и статической сборкой GitHub Pages. Новый порядок блоков и компактные правила действуют **только при ширине до 767 CSS px включительно**. На 768 px и шире используется прежний интерфейс. Проверка ширины основана на `matchMedia`, без User-Agent.

Не менялись банк заданий, теория как учебный контент, валидаторы, события обучения, XP, Win Streak, самооценка, подписки, тарифы, авторизация, ключи/схемы хранилищ и алгоритмы навигации. Миграция пользовательских данных не требуется.

## Что обнаружено

- На мобильной главной восемь учебных переходов находились после двух высоких карточек XP. Теперь три наиболее частых дополнительных действия стоят сразу под продолжением, а общий и предметный XP показаны рядом при достаточной ширине текста.
- В каталоге серия, случайная практика и пояснения предшествовали выбору номера. На телефоне они перенесены ниже основного выбора.
- Поиск теории находился после экзамена/предмета; заголовок материала был вне карточки, а практика — после вспомогательных пояснений.
- После открытия решения переходы оставались над разбором. На телефоне они теперь под итоговым ответом, без повторных видимых кнопок.
- В профиле справка стояла первой; в Premium подробный список возможностей предшествовал срокам и ценам; активный учебный вариант начинался с развёрнутой сетки номеров.
- Меню «Ещё» начиналось с тренера, а не с бесплатных учебных инструментов.

Это проверенные особенности прежней разметки, а не выводы о частоте использования на основе несуществующей аналитики.

## Двенадцать экранов

| Экран | Что изменено на телефоне |
| --- | --- |
| Твоя подготовка | Реальный экзамен/предмет; продолжение или честный старт без истории; быстрые ошибки/избранное/вариант; XP и обе серии; спокойная ссылка Premium. |
| Задания — каталог | Экзамен/предмет, уровень при наличии, режим, части и реальные номера; вторичные действия ниже. |
| Теория — каталог | Поиск первым, экзамен/предмет, фильтры части/номера, компактный список; «О материалах» свёрнуто внизу. |
| Краткий конспект | Возврат отдельно, закладка внутри карточки, заголовок и материал; подробный конспект и практика рядом; дополнительные сведения ниже. Полный конспект также сохранён целиком. |
| Задание | Исходное условие и поле ответа сохранены; после ошибки разбор становится главным действием, доступно самостоятельное исправление. |
| Решение | Пошаговый разбор и ответ; единственная пара «Следующее / Предыдущее» под решением. До проверки разбор недоступен. |
| Учебный вариант | Контекст и таймер, раскрываемый выбор номера, текущая задача; прежние ответы, сохранение, переходы и завершение. |
| Мои ошибки | Фильтры и реальные карточки выше служебной информации; неизменные переходы к заданию/теории. |
| Мой профиль | Пользователь → настройки оформления, концентрации и перерывов → подписка → справка → данные. Прежний размер текста сохранён, новый переключатель не добавлялся. |
| Точка Premium | Краткое описание → срок → три реальные тарифные карточки → дополнительные пояснения. Оплата и trial не активируются фиктивно. |
| Мой тренер | В деморежиме настоящие рекомендации/пустое состояние выше объяснений. В Free честный Premium-экран и прежний робот; методика раскрывается ниже. |
| Разделы / Ещё | Ошибки, избранное, вариант, профиль; затем тренер, умное повторение, справка, Premium. Платная метка только у тренера и умного повторения. |

Связанные экраны «Избранное», «Умное повторение», справка и карточка подписки также используют согласованную мобильную плотность. Основная нижняя навигация остаётся из пяти пунктов и учитывает safe-area. В концентрации скрывается по прежним правилам.

## Размеры и формулы

- Интерфейс 15 px; условия и длинный текст теории 16 px, line-height 1,55–1,6; заголовки страниц 22 px, карточек 18 px; вторичные подписи 13–14 px; кнопки 15 px.
- Общие карточки 16 px, компактные блоки 14 px; промежутки около 18 px. Области нажатия от 44 px. Редактируемые поля от 16 px, чтобы Safari не увеличивал страницу при фокусе автоматически.
- Числа XP, толщина шкал, область пламени и правила цветов не менялись. При увеличенном тексте карточки могут становиться в одну колонку.
- Формулы имеют собственный горизонтальный скролл, `min-width: 0` у контейнеров и доступное начало/окончание выражения. Размер математического блока обычно 17 px; KaTeX около 17,85 px. Нет `zoom`, масштабирования страницы или обрезания правой части ради скрытия переполнения.
- На планшете остаются прежние параметры чтения: колонка длинной теории до 640 px, основной текст 20 px / 500 / 1,65 при обычном размере текста.

## Запуск и публикация

Локально: `npm install`, затем `npm run dev` и открыть `http://localhost:3000`.
Для GitHub Pages: `npm run build:pages`; статические файлы находятся в `out`, базовый путь уже настроен. Маршруты после `#` не требуют серверных перенаправлений. Сохраняется действующий способ публикации исходников и собранной ветки `gh-pages`.

## Ограничения

- Проверки в Chromium с заданными viewport не заменяют Safari на физическом iPhone/iPad, его экранную клавиатуру и реальную safe-area. На устройстве стоит проверить чтение, длинную формулу, нижнюю панель, ввод ответа и концентрацию.
- Данные остаются локальными в браузере. Облачной синхронизации, аккаунтов и настоящих платежей этот этап не добавляет.
- Иллюстративные цифры и задачи макетов не переносились в продукт. Premium не получил новых действующих функций от одной перестановки интерфейса.
