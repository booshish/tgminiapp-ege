# Проверка расширения «Точки»

Дата: 21.10.2026. Проверяется существующее приложение, исходный срез `1c8d914`. Все перечисленные браузерные проверки выполнены в Chromium через Playwright; это не физический Safari/iPad.

## Автоматические проверки

- `npm test`: **179 тестов**, без пропусков и ошибок.
- `npm run lint`, `npm run typecheck`: успешно.
- `npm run content:check`: 448 задач в данных, 432 доступны; все 44 номера связаны с задачами, решениями и теорией.
- `npm run content:report`: таблица по каждому номеру/теме/прототипу, сравнение с исходным срезом.
- `npm run content:seed -- /tmp/tochka-content-seed.json`: детерминированный экспорт; SHA-256 `0e730ceebcaa289cae84b4b28a401b3fcd29108b29a1a7e0c302d4ca9f680acb`.
- `npm run build:pages`: статический экспорт с base path `/tgminiapp-ege/`, без демонстрационного Premium в публичной сборке.
- `git diff --check`: успешно.

Тесты включают независимые вычисления ответов генераторов и ограничения параметров, отсутствие дублей, сохранение старых ID, все формулы KaTeX, связи теории/практики, миграции, повреждённые данные, автоматическую проверку, XP/серии и самооценку. Первая часть проверяется точно; математическая корректность не подтверждает полноту охвата официального экзамена или калибровку сложности.

## Ограничения

- ФИПИ и публичный адрес GitHub Pages из среды возвращают CONNECT HTTP403. Официальная сверка содержания/времени/критериев и HTTP-подтверждение публикации недоступны; ограничения сети не обходились.
- Варианты авторские, по предварительной структуре 2026 года. Подтверждённый официальный пробник и полный охват всех подтипов не заявляются.
- Нет аккаунтов, серверной БД, облачной синхронизации, настоящей покупки или защищённого Premium. Данные локальные; одновременные записи нескольких вкладок не являются серверной транзакцией.
- Самооценка второй части не заменяет эксперта. Уровни сложности требуют последующей калибровки.
- Реальный iPad: проверить 5–10 минут чтения в обеих ориентациях, прокрутку формул, ввод и клавиатуру. Субъективное устранение усталости глаз удалённо не подтверждено.
