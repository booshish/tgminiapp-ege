# Двухрядная панель и автосброс — частичная контрольная точка

Выполняется только безопасный UI-пакет; вся задача НЕ завершена.

Первый ряд: возврат в каталог и направление/предмет/уровень; в фокусе справа компактный выход. Второй: существующие режимы, hide-solved, тема и счётчик. Панель темы переиспользуется без изменения фильтрации. Общий дублирующий back/eyebrow внутри карточки скрыт только в практике, функции закладок сохранены.

Удалена причина обрезания: focus main больше не имеет height:100dvh с вложенным overflow:auto и отдельной неподвижной полноширинной строкой. Возвращена обычная прокрутка документа. Sticky — только сама кнопка 64×64 в узкой боковой колонке 64px + 12px gap. У кнопки нет полноширинного sticky/fixed родителя, маски или прозрачного overlay. Для текста зарезервирована именно эта боковая область; он не проходит под кнопкой даже на середине/конце документа. Оставшаяся ширина не ограничена старым max-width. Узкие экраны допускают перенос.

Автосброс и меню ⋯ НЕ реализованы и не включены. Объективное место интеграции: practice-view.ts вычисляет completion из legacyRecords, game.checks, answer_checked events, сохранённых проверок и self-assessment XP events. Удаление/сброс этих данных разрушает историю или защиту XP. Для безопасной реализации нужен согласованный persisted reset-epoch по предмету/экзамену с отдельной проекцией новой попытки, защита от повторного выполнения между вкладками, сохранение исторического attempt и дедупликации XP. Это не решено простым localStorage-таймером; такой таймер и не добавлялся. Нельзя выдавать UI-настройку без этой интеграции за готовую функцию.

Следующий этап: адресно продолжить с practice-view.ts, PracticeTaskState/PracticeSession в practice.ts, use-practice-session.ts, learning-events.ts и актуальной схемы сериализации. Спроектировать reset epoch и новую попытку без удаления истории, затем интервалы calendar/month-end, fake-clock проверки, cross-tab reconcile и только потом настройку ⋯/уведомления. Значение по умолчанию — never. Проверить отсутствие синхронизации между устройствами, не обещать её без существующего backend. В текущем UI никаких действий сброса нет.

Банк, taskId, ответы, критерии, XP и подписки не менялись. Регрессия taps обновлена на геометрию первого ряда и отсутствие горизонтального пересечения кнопки с контентом на 0/50/100% прокрутки документа. Safari/iPad физически недоступны; используется Chromium touch emulation.
