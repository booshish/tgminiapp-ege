# Интерфейс и навигация — 2026-10-23

## Реализовано

- Начиная с 768 px — боковая панель 76 px с иконками. Кнопка меню разворачивает её до 236 px; соседняя кнопка скрывает полностью. Контент занимает освободившееся место. Предпочтение хранится отдельно в `tochka-sidebar-v1`; при недоступном хранилище меню работает в памяти. Панель не перекрывает страницу, длинное меню прокручивается самостоятельно.
- В основном меню: Главная, Задания, Теория, Конспекты, Мой тренер, Мои ошибки, Профиль, Плюс. Конспекты — существующие сохранённые материалы теории (`#/favorites?kind=theory`), без нового редактора или хранилища. Общий список закладок остаётся доступен. Нижняя навигация телефонов сохранена; отдельное повторение из меню удалено.
- «Задания» всегда открывают каталог с четырьмя входами: по номерам, варианты, ошибки, сохранённые задания. Продолжение последней задачи вынесено в явную кнопку; по номерам продолжают работать прежние сессии. Учебные варианты используют тот же контроллер и историю; вход в список не удаляет незавершённую попытку. Для предметов без вариантов есть понятная подпись.
- В русских заданиях с нумерованным исходным текстом источник и вопрос/ответ выводятся раздельно. При доступной ширине области от 860 px — две колонки, при меньшей — последовательное чтение. Ширина строки ограничена; на широком экране ответ остаётся рядом при прокрутке. Исходные данные банка не изменены.
- Сохранённые задания и конспекты открываются через существующие закладки, включая русский язык и другие опубликованные предметы. Убрана ошибочная подпись «Математика» для русских закладок; добавлен фильтр предметов.
- Интервальное повторение доступно внутри «Моего тренера». Старая ссылка `#/review` совместима и отображается как вложенная страница тренера. Главная и меню больше не предлагают отдельный раздел «Умное повторение». Алгоритм, интервалы, журнал ошибок и ограничения Free сохранены.
- Пользовательское название подписки — «Точка Плюс», меню — «Плюс», кнопки — «Подключить Плюс», профиль — «Подписка «Плюс»». На карточках указаны полное название, число предметов и прежняя стоимость. Внутренние идентификаторы Premium, цены, сроки, права и платёжное поведение сохранены. Оплата, как раньше, ещё недоступна.

## Проверка

- `npm run lint`, `npm run typecheck` — успешно.
- Общий набор: 380/380 тестов. Проверены сохранение по номерам/предметам, XP и серии, интервалы повторения, учебные варианты, подписки и цены. Банк, экзаменационные данные и алгоритмы обучения не менялись; отдельная ведомость исходных текстов ЕГЭ также проходит `--check` без обновления отпечатков.
- Новый браузерный сценарий: меню в трёх состояниях, перезагрузка, восемь разделов на планшетах, ОГЭ/ЕГЭ/база/профиль, ошибочный и верный ответы, продолжение, русские закладки, сохранённая теория, вариант и его черновик/история, вложенное повторение, названия и недоступность оплаты. Для длинного текста используется только временное расширение DOM, без записи в банк.
- Проверены ширины 320, 375, 430, 767, 768, 1024, 1440, 1920 px; оба режима меню на 768/1024, светлая/тёмная тема. В development-сборке прошли 9 групп, ошибок страницы/горизонтального переполнения/перекрытия панелью нет. Скриншоты: `/workspace/scratch/qa-workspace`.
- `npm run build:pages` — успешно, выполнена одна итоговая сборка. На ней повторно прошли 9 групп нового браузерного сценария (включая режим концентрации) и 9 групп `test-browser-subjects.py`, без ошибок страницы. Production проверен по адресу с префиксом `/tgminiapp-ege`; перед запуском поднят локальный HTTP-сервер для `out`. Используется существующая конфигурация GitHub Pages и ветка `gh-pages`, без новых workflow и изменений настроек.

Незавершённых функций в рамках запроса нет. Состояние итоговой сборки/публикации подтверждается отдельно после выполнения, а не предполагается из наличия коммита.
