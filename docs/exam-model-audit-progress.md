## Безопасный следующий запуск

1. Прочитать `generator-readiness-summary.md`; в JSON читать **только** `generatorAudit` нужного modelId/number/subtype, не весь большой отчёт.
2. Для массовой генерации вызывать `requireReadyGenerator`: разрешён конкретный READY-подтип, не весь номер. Gate сверяет SHA реализации и отклоняет устаревшие доказательства. Наличие старого `generation.status=algorithm-ready` или пяти готовых задач не заменяет новый gate.
3. Первыми масштабировать **ЕГЭ химию №26–28** (три перечисленных численных подтипа), **ЕГЭ информатику №14** (power-minus-offset-digit-count), **ЕГЭ биологию №3–4** (два подтипа каждого номера). Только заявленные диапазоны, постоянная независимая проверка, прежний импорт и редакционный контроль дубликатов. Это тренировки по проектам, не официальные КИМ.
4. Следом подтвердить критерии ОГЭ-информатики и расчётных физики/химии ОГЭ, географии, расширять их подтипы после адресных доказательств. История/общество — ограниченные проверенные справочники; перестановка одного списка не считается разнообразием.
5. Математика: целевой профиль 2027 **20/33**, runtime 2026 **19**. Нужна карта соответствия каждого затронутого задания; не перенумеровывать и не переносить результаты автоматически. База/ОГЭ тоже требуют поэлементной карты, а не признания семейств официальными только по номеру.
6. Полные кодификаторы и поэлементные рубрики остальных направлений не завершены. Русский/литература/языки требуют содержательного редактора, полноценных правомерных текстов, реальных аудио/карт/экспериментальных ресурсов и подходящей экспертной/самопроверки. Сейчас их нельзя безусловно масштабировать.
