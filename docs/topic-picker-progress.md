# Выбор темы на экране решения — 2026-10-28

Завершена доработка существующего NumberTrainingFilters, без нового экрана, банка или классификатора.

- Компактная кнопка «Выбрать тему» перед условием показывает текущий выбор и открывает панель в потоке страницы. Повторное нажатие, отдельная кнопка и Escape закрывают её; фокус возвращается на кнопку.
- Тема, подтема, подтип и источник применяются сразу через существующий practice.start / URL / session / lazy loader. Блокировка полей на время загрузки исключает конкурирующие изменения.
- «Все темы» снимает тему/подтему/подтип, сохраняя независимый источник. «Сбросить все фильтры» возвращает весь банк номера.
- Тематические опции представлены только существующими классификациями с подтверждённой авторской подробной рубрикой (не утверждение экспертной полноты номера). Общие неподтверждённые ярлыки не выдаются за подробную разбивку; соответствующие задачи сохраняются в общем режиме. Нулевые источники не показаны как наполненные категории. Счётчики вычисляются по прежнему metadata overlay, с учётом иерархии и источника, без загрузки условий.
- Возврат к той же карточке номера сохраняет фильтры; смена контекста очищает их. Перезагрузка/история и общий stable-ID черновик работают через прежнее хранилище.
- Исправлено прежнее зависание явной ссылки номера без task ID: отсутствие legacy-индекса теперь допускает восстановление только точно совпадающего контекста. Ссылки с конфликтующим ID и чужие номера не получают подменную задачу.
- Пустая подборка показывает понятное состояние и «Все темы»; источник при необходимости сбрасывается отдельно. Новые классификационные данные, задания, ответы, ID, цены и алгоритмы XP не изменялись.
