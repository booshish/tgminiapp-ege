Остальные 1 233 активные задачи имеют только общую тему и статус `needs-editorial-review`. В частности, 910 русских задач не превращены в 910 «подтипов» по карточным prototypeId.

Заполнены задачами 214 позиций. **0 номеров объявлены исчерпывающе классифицированными**: полные перечни существенных подтипов и индивидуальные коды ФИПИ пока требуют проверки. Ссылки/коды уровня номера не выдаются за доказанную принадлежность конкретного условия.
- Источники отделены от тем: оригинальные «Точки», открытый банк/демоверсии ФИПИ, ЕГКР, официальные прошлые экзамены, другие подтверждённые, неподтверждённые. В текущем банке все записи относятся к собственным материалам по декларациям/файлам проекта; 0 записей без такого происхождения. Это не независимая юридическая экспертиза. Ни одной записи не присвоена метка ФИПИ/ЕГКР по сходству или структурной ссылке. Сторонних импортов нет.
- Год происхождения неизвестен → `null`; сохранён отдельно год исходных экзаменационных требований. Идентификаторы, исходные файлы, авторские декларации и статус прав доступны в машинной карте через общий `sourceRecords`.
- Единая раскрывающаяся панель в решении номера: тема → подтема, подтип, источник; реальные счётчики, применение, возврат ко всем задачам. Фильтры сохраняются в прежних URL/selection/session, общий черновик/история остаются по стабильному taskId. Метаданные фильтров не содержат условий и ответов, ленивая загрузка использует их до чтения shards.
- 31 существующий контракт генератора снабжён классификацией/форматом/проверкой/готовностью. `planSubtypeGeneration` — только заказ точного READY-подтипа с количеством 1..1000 для прежнего конвейера; не второй движок и не запуск массовой генерации. Политика Плюса/бесплатного доступа и аналитика не менялись.

## Файлы и воспроизведение

- `scripts/build-task-taxonomy.mjs` — только создание метаданных и отчётов из существующего кода/доказательств, не генератор условий.
- `src/lib/content/task-taxonomy-data.ts`, `src/lib/task-taxonomy.ts` — компактный клиентский sidecar и общий фильтр.
- `docs/task-classification-map.json` — полная карта exam→number→subtype→topic→subtopic→source→count/status, исходные fingerprints и контракт генераторов.
- `docs/task-classification-summary.md` — компактная сводка всех 30 направлений и список заполненных номеров для редакционной проверки.
- ID не зависят от порядка: семантические темы/подтемы получают детерминированные ID, подтипы — ID собственного семейства. Переименование смысла/слияние требует явной карты миграции; не менять опубликованные IDs молча.
