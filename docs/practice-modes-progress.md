## Реализовано

- «По одному»: прежние поля ответа/проверка/решение, постоянные «Назад» и «Пропустить / Следующее». Навигация не вызывает проверку, запись ошибки или XP. Черновики остаются в общем существующем `taskStates` по стабильному taskId.
- «Лента»: полные условия, формулы, существующие рисунки и скачиваемые материалы; по 12 карточек, переход «Решить» открывает ту же задачу и прежний обработчик ответа. Количество DOM-карточек ограничено, следующая страница использует прежний проверяющий SHA256 shard-loader.
- Общие тема/подтема/подтип/источник и «Скрыть решённые» (по умолчанию включён). Неверные ответы, открытия, пропуски и неподтверждённые черновики не считаются решением. Подтверждённая самопроверка, в том числе 0 баллов, обозначается именно самопроверкой, не экспертной оценкой. Только что проверенная карточка остаётся доступной для чтения результата/решения.
- Режим, предпочтение фильтра и ограниченные снимки страницы/прокрутки сохраняются отдельно от прогресса в `tochka-practice-view-v1`. Смена темы сбрасывает только позицию списка. Черновики, история, закладки, XP и серия используют прежние хранилища и алгоритмы.
- Сессии хранят стабильные ID всех подходящих задач из metadata index, но не требуют загрузки всех условий. Bootstrap восстанавливает реальные черновики/события/закладки/текущий ID, а не скачивает все candidate IDs сессии. Учебные варианты сохраняют прежний загрузчик по умолчанию.
